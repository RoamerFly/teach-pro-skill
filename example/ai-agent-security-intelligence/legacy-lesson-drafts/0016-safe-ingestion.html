第 16 课 · 阶段六 · 毕业项目

安全采集与归一化：构建只读情报入口

实现域名固定、响应受限、模式验证、可离线测试的情报采集与归一化层。

预计时间
240 分钟
学习形式
图解 → 推导 → 代码 → 项目

今天要解决什么

先构建只读数据入口，再让 Agent 使用它。今天你会运行课程附带的本地夹具，实现一个无法访问任意 URL 的 source adapter。

  • 用 source adapter 隐藏 URL 和协议细节
  • 验证内容类型、大小、状态和 Schema
  • 保存原始证据哈希并输出统一 Finding

固定来源适配器

class SourceAdapter(Protocol):
    source_id: str
    def fetch(self) -> bytes: ...
    def parse(self, raw: bytes) -> list[Evidence]: ...

class CisaKevAdapter:
    source_id = "CISA-KEV"
    endpoint = "https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json"
    # endpoint 是程序常量，不由模型或用户传入

Agent 只看见 refresh_source("CISA-KEV")，source registry 在服务端把 ID 映射到固定 adapter。这样工具参数不会变成通用网络通道。

网络边界

设置连接/读取超时、最大响应字节、允许 MIME、最多重定向、最终域名复核和速率限制。TLS 错误不能被模型要求忽略。解析前保存哈希；解析失败时保留失败事件，但不要把任意响应正文写进模型上下文。

规范化不抹去差异

将 CVE ID、厂商、产品、日期等映射到统一字段，同时保留 source-specific 原始字段和 evidence_id。缺失值为 null，不让模型猜。时间统一到 UTC，但保留原始时区/字符串用于审计。重复记录按 CVE 聚合，不把不同来源的描述互相覆盖。

实验代码路径

课程目录中的 labs/secure_cti_agent 提供离线安全骨架。先运行：

cd labs/secure_cti_agent
python -m unittest -v
python app.py

应用只读取合成夹具，不发送网络请求。完成课程后再新增真实 adapter，并用依赖注入保留离线测试。

练习与可见产出

实现 EPSS adapter

接口只接受已验证的 CVE 列表（最多 50 个），固定调用 FIRST endpoint。为超时、非 JSON、缺字段、额外字段、重复 CVE 和超大响应写测试。

安全检查

调用者不能传完整 URL、header 或代理；日志不写 API 凭据；返回记录带查询日期和 source_id。

精选资源

NVD Vulnerabilities API 来源：NIST NVD · 位置：CVE API 2.0 参数与响应 · 预计：20 分钟

设计 NVD adapter 时核对官方参数、分页和速率要求。

Known Exploited Vulnerabilities JSON 来源：CISA · 位置：完整 JSON feed · 预计：10 分钟

观察真实字段，但不要在教程核心运行中依赖在线可用性。

带走这个心智模型

安全采集器把开放互联网压缩成少数固定、受限、可验证的 source adapter；规范化统一比较维度，但永远保留来源和原始证据。

复习安排

  • 24 小时后：列出一次安全 HTTP 获取的六个限制。
  • 7 天后：用恶意夹具测试解析器不会产生工具调用。
  • 阶段末：为新来源建立离线夹具后才接真实网络。
