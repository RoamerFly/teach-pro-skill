可打印学习工具

安全 Agent 检查表

开发、评审与发布前使用的压缩清单；它不能替代各课的首次学习。

设计时

  • 目标、用户与非目标明确
  • 优先确定性工作流，局部才用 Agent
  • 资产、主体、信任边界和滥用场景已画
  • 外部内容与高权限执行路径隔离

工具与数据

  • 工具窄、强类型、默认只读
  • 校验与授权分离并位于模型外
  • 任意 URL、私网、重定向和响应大小受限
  • 租户、来源、时间、哈希与 TTL 完整

运行时

  • 步数、工具、token、时间、重试有上限
  • 高影响动作参数绑定审批
  • 错误不会泄露堆栈、密钥和内部路径
  • 日志脱敏、可追、有限保留

发布前

  • 单测、轨迹测试、行为评测分层
  • 注入、越权、投毒、泄露、耗尽均有回归
  • 高风险不变量零失败
  • 残余风险、负责人和恢复步骤已记录
