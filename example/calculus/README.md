# 高等数学课程示例

本示例来自 TeleAgent 3.1.1 中使用学途智伴的真实运行，学员由 AI 模拟为零基础大学新生。

从 `index.html` 查看路线，依次体验入门评估、函数图像正式课、图像平移补充课和极限直觉正式课。针对平移误区补充讲解，同时继续安排新正式课，展示作答如何影响后续教学。

安装 Python 3.10+，运行对应平台的 `start-course` 启动器，即可保存自己的练习、疑难与课内聊天。课程设置中可连接自己的答疑模型。

运行过程与验证见 [TeleAgent 运行记录](../../evals/records/2026-11-27-teleagent-live.json)。
