起点诊断

入门评估

用 10—15 分钟看看你的函数、代数与图像基础，帮助决定第 2 课是直接进入极限，还是先补一小段代数。题目没有分数压力，不会做就写“不确定”。

使用方法

先作答，再展开每道题的参考标准。评估共 2 道选择题 + 3 道开放题。开放题写下你的思路即可，不必追求标准格式。

使用课程启动器时，答案会自动保存到课程目录，教学 AI 在下次对话中可以直接读取。直接双击 HTML 打开时，答案只保存在浏览器，可下载备份或手动粘贴。

评估任务

选择题 1 · 函数记号

f(3) 等于多少

已知 f(x) = 2x + 1，求 f(3)。

选择题 2 · 定义域

哪些 x 可以让式子有意义

函数 f(x) = 1 / (x − 2) 的定义域是（ ）。

开放题 1 · 图像阅读

描述 y = x² 的增减

在坐标平面上画出 y = x² 的草图，并用自己的话说明：当 x < 0 时，x 增大，y 怎样变化？当 x > 0 时呢？

查看提示

从左往右移动 x，观察曲线上的点是在下降还是上升。也可以代入 x = −2、−1、0、1、2 算出对应的 y 值比较。

查看参考标准

在 x < 0 的一段，x 从负值增大到 0 时，y 从较大的正值减小到 0，曲线下降，所以函数在这一段递减；在 x > 0 的一段，x 增大时 y 增大，曲线上升，所以递增。x = 0 时 y 取得最小值 0。

检查点：是否同时说清了两侧的增减方向，并用“x 增大时 y 怎样变”来描述，而不是只说“曲线像个 U”。

开放题 2 · 代数基础

解一元二次方程

解方程 x² − 3x + 2 = 0，写出你的过程。能用因式分解就用因式分解，也可以使用求根公式。

查看提示

找两个数，它们的乘积是 2，和是 −3。把 x² − 3x + 2 写成两个一次因式的乘积。

查看参考标准

x² − 3x + 2 = (x − 1)(x − 2)。两个因式的乘积为 0，说明至少有一个因式为 0，所以 x − 1 = 0 或 x − 2 = 0，得到 x = 1 或 x = 2。

检查点：分解是否正确；是否由“乘积为 0”推出“至少一个因式为 0”；两个根是否都写出。

开放题 3 · 学习起点

你最担心哪一部分

写一个你担心的具体场景，例如“看到 lim 符号不知道从哪下手”“三角函数公式记不住”“积分不知道怎么开始”。这题没有标准答案，用来安排讲解顺序和例题。
