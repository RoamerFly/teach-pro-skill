## Phase 1 — 函数与极限
### Outcome
能读懂函数记号与图像，判断简单函数的定义域，理解“趋近”的含义，并独立计算基础极限。

### Core capabilities
- [ ] 把 f(x) 读成输入—输出规则，正确计算 f(a)
- [ ] 从表达式判断定义域（分母、偶次根号）
- [ ] 从图像读出单调区间、最值、奇偶性
- [ ] 用表格与图像说明 x→a 时函数值的趋势
- [ ] 用代入、因式分解、有理化计算基础极限

### Suggested lessons
1. 函数与图像：把 f(x) 读成一条曲线
2. 极限的直觉：x 靠近 a 时，f(x) 靠近什么
3. 极限的计算：先代入，再变形
4. 连续与间断：图像在哪里断开

### Current supplements
- 第 1 课补充 · 图像平移：加在外面抬高，写在括号里左右移动（待作答）

### Gate to advance
- 能独立求 3 类基础极限（代入型、0/0 因式分解型、根式有理化型），并说出每一步依据。
- 能画出一个二次函数的草图并读出定义域、值域、单调区间。

### Review plan
- 第 2 课开始前，用 5 分钟回忆定义域与图像读法。
- 第 4 课后安排一次间隔复习：混合极限与函数图像题。

## Phase 2 — 导数与变化率
### Outcome
理解导数是瞬时变化率与切线斜率，能对常见函数求导并用导数解决单调性、极值与最值问题。

### Core capabilities
- [ ] 用变化率解释导数
- [ ] 掌握幂、指数、对数、三角函数的求导公式
- [ ] 使用和差积商与复合函数求导法则
- [ ] 用导数判断单调区间与极值
- [ ] 求闭区间上的最值

### Suggested lessons
1. 导数：从平均速度到瞬时速度
2. 求导公式与法则：把复杂函数拆开
3. 单调性、极值与最值：用导数读图像

### Gate to advance
- 能对多项式、指数、对数与简单复合函数求导。
- 能写出一阶导数，列表判断单调性与极值，并给出闭区间最值。

### Review plan
- 每节新课开始前混合 2 道求导题；第 3 课后安排一次延迟提取。

## Phase 3 — 积分与累积
### Outcome
理解定积分是面积与累积量，掌握基本积分公式与牛顿—莱布尼茨公式，能计算基础定积分。

### Core capabilities
- [ ] 用分割—近似—求和解释定积分
- [ ] 掌握基本不定积分公式
- [ ] 使用换元法处理简单积分
- [ ] 用牛顿—莱布尼茨公式计算定积分
- [ ] 用定积分求简单面积

### Suggested lessons
1. 定积分：把面积切成细条累加
2. 原函数与不定积分：反过来求导
3. 牛顿—莱布尼茨公式：积分与导数的桥
4. 定积分的应用：面积与累积量

### Gate to advance
- 能独立计算 5 道基础积分（幂函数、指数、简单换元）。
- 能用定积分表示并计算一个简单曲边梯形面积。

### Review plan
- 积分公式每周滚动回忆一次；第 4 课后与导数混合复习。

## Phase 4 — 期末整合
### Outcome
按期末题型组织知识，能在限时条件下完成基础题与常见中档题，并对错题做归因。

### Core capabilities
- [ ] 识别题目对应的章节与方法
- [ ] 在 90 分钟内完成一套基础模拟卷
- [ ] 对错题写出错误类型与修正步骤

### Suggested lessons
1. 期末题型串讲：极限、导数、积分各考什么
2. 模拟卷与错题复盘

### Gate to advance
- 模拟卷基础题正确率达到可接受水平，错题能说出错因并重做正确。

### Review plan
- 考前一周做两次间隔模拟；每次只复盘错题与不确定题。
