第 1 课 · 函数与图像：把 f(x) 读成一条曲线

用一个二次函数，把函数记号、定义域、图像和单调性串起来。这张图也是下一课理解“极限”的地图。

课程类型
正式课
预计时间

第 1 课 · 待作答

今天要解决什么

题目问“f(2) 等于多少”“这个函数的最小值在哪”“x 从 0 增大时函数怎么变”。这三问看起来分散，其实都在读同一张图：一个输入对应一个输出，所有输入输出配成曲线。

今天用 f(x) = x² − 2x 做完整示范。学完你能：

  • 把 f(a) 算对，并说清“代入”把哪个数放到了哪里。
  • 从表达式判断定义域：分母不能为 0，偶次根号内不能为负。
  • 用配方法画二次函数草图，读出顶点、单调区间和值域。

先修：坐标平面上的点 (x, y)，以及把数代进式子的计算。例如 2×3+1=7。课内会从这两件事开始，不熟也能跟上。

开始前只需两件事

坐标平面：横轴记录输入 x，纵轴记录输出 y；一个点写成 (x, y)。

代入：把括号里的数放到式子里每个 x 的位置，再按先乘除后加减计算。例如 f(x)=2x+1 时，f(3)=2×3+1=7。

函数是输入—输出规则

函数给每个允许的输入配一个输出。写成 f(x)，读作“f 在 x 处的值”。这里的 f 是规则的名字，x 是输入；f(x) 不是 f 乘 x。

f(x) = x² − 2x

这条规则说：拿到一个输入 x，先把它平方，再减去它的 2 倍。输入 3 时，先算 3²=9，再算 2×3=6，最后 9−6=3。所以 f(3)=3。

输入 x代入后的计算输出 f(x)
00² − 2×00
11² − 2×1−1
22² − 2×20
33² − 2×33

把括号里的内容整体放进每个 x 的位置，这条规则对任何输入都成立。例如输入 x+1 时，f(x+1)=(x+1)²−2(x+1)，而不是在原来的式子后面加 1。

常见错法：把 f(3) 读成 f 乘 3，或者把 f(x+1) 写成 f(x)+1。正确做法是先圈出括号里的整体，再把它替换到每个 x 的位置。练习 3 会专门检查这一点。

图像：把每一对输入和输出画成点

每个输入 x 产生一个输出 f(x)，把它们配成点 (x, f(x)) 画在坐标平面上，所有点连起来就是函数的图像。上面的表格给出 5 个点；曲线把它们之间的所有输入也补上了。

图像把“代入—计算”变成一眼能看出的形状。看到曲线向下弯到底再向上，后面判断最小值、单调区间都会快很多。

定义域：哪些输入允许进入规则

定义域是所有能让式子有意义的输入 x 组成的集合。常见的有两条限制，先分别看，再取交集。

分母不能为 0

f(x)=1/(x−2) 中，x=2 时分母为 0，除法没有结果，所以定义域是 x≠2。其余实数都可以输入。

偶次根号内不能为负

f(x)=√(x−1) 中，根号内需要 x−1≥0，所以定义域是 x≥1。x=1 时根号为 0，可以取。

两条限制同时出现时，取同时满足的部分。例如 f(x)=√(x−1)/(x−3)：根号要求 x≥1，分母要求 x≠3。把 x=3 从 [1, +∞) 中挖掉，得到 [1, 3) ∪ (3, +∞)。

[1, 3) ∪ (3, +∞)

区间记号里，方括号表示端点包含，圆括号表示端点不包含；∪ 表示把两段合在一起。x=3 处函数没有定义，所以两侧分成两段。

检查顺序：先列出每条限制（分母≠0、根号内≥0），再把所有条件同时满足的 x 留下。最后用区间或不等式写出结果。

画二次函数草图：先配方，找顶点

二次函数 y=ax²+bx+c 的图像是抛物线。a>0 时开口向上，a<0 时开口向下。画草图的关键是找到顶点：把式子配成 a(x−h)²+k 的形式，顶点就是 (h, k)。

x² − 2x = x² − 2x + 1 − 1 = (x − 1)² − 1

这里加了 1 又减了 1，式子的值没有变，但前三项凑成了完全平方 (x−1)²。于是 f(x)=(x−1)²−1：平方部分最小为 0，在 x=1 时取到，所以最小值是 −1，顶点为 (1, −1)。

  1. 配方：把 x²+bx 补成完全平方，加上再减去同一个数。
  2. 读顶点：写成 (x−h)²+k 后，顶点是 (h, k)，开口方向看 x² 前的系数正负。
  3. 找与坐标轴的交点：令 y=0 解方程得 x 轴交点；令 x=0 得 y 轴交点。
  4. 描点连线：顶点加两侧各一两个点，按抛物线形状连起来。
完整示例

画 f(x)=x²−2x 的草图

第 1 步，配方：x²−2x=(x−1)²−1。顶点是 (1, −1)，x² 前系数为 1>0，开口向上。

第 2 步，找 x 轴交点：令 f(x)=0，得 x²−2x=0，提公因式 x(x−2)=0，所以 x=0 或 x=2。图像经过 (0, 0) 和 (2, 0)。

第 3 步，找 y 轴交点：令 x=0，得 f(0)=0，与上面的 (0, 0) 是同一个点。

第 4 步，补两个点并连线：x=3 时 f(3)=3，x=−1 时 f(−1)=3。左右对称，连成图 1 的抛物线。

结果：顶点 (1, −1)，与 x 轴交于 0 和 2，开口向上。草图只需要顶点、两个交点和左右各一个辅助点。

从图上读出单调区间、最值和值域

单调性描述“x 从左往右增大时，y 是上升还是下降”。看图 1：从顶点左侧走到顶点，曲线下降；从顶点往右走，曲线上升。

x < 1 的一段

x 从左边增大到 1 时，y 从较大的值减小到 −1。函数在 (−∞, 1] 上递减。

x > 1 的一段

x 从 1 继续增大时，y 从 −1 开始增大。函数在 [1, +∞) 上递增。

顶点给出最小值 −1，在 x=1 处取到。抛物线向上开口且没有最高点，所以值域是所有大于等于 −1 的实数：

值域：[−1, +∞)

这里区间端点 −1 能取到，所以用方括号。单调区间与值域都来自同一张图，先找顶点，再向两侧读升降。

把目光放到顶点附近：x 从 1 的左侧靠近 1，y 靠近 −1；x 从 1 的右侧靠近 1，y 也靠近 −1。这个“靠近”正是下一课极限要研究的内容。今天先会读图，下一课再把“靠近”写成 lim。

条件变化：分母、根号与上下平移

同一个规则改动一处，定义域或图像就会跟着变。下面三种变化在期末题里经常出现。

  • 加分母：g(x)=1/(x−1)。定义域变成 x≠1。x 从两侧靠近 1 时，分母绝对值越来越小，函数值绝对值越来越大；图像在 x=1 处断开。
  • 加根号：h(x)=√(x−1)。定义域变成 x≥1，图像从点 (1, 0) 开始向右延伸；x<1 没有实数输出。
  • 整体加 3：f(x)+3=(x−1)²+2。图像整体向上平移 3 个单位，顶点从 (1, −1) 移到 (1, 2)，值域从 [−1, +∞) 变成 [2, +∞)。

这三条变化都指向同一件事：先看表达式允许哪些输入，再看图像的关键点被移到了哪里。

练习 1：完整画一张草图

练习 1 · 引导

把 f(x)=x²−4x+3 画成草图

依次写出：配方后的形式、顶点、与 x 轴的交点、值域、单调区间。最后用一句话说明开口方向。

查看提示

先把 x²−4x 补成完全平方：x²−4x+4=(x−2)²。为了不改变式子的值，加上 4 再减去 4。令 y=0 时，尝试把 x²−4x+3 分解成两个一次因式。

查看答案与解析

配方：x²−4x+3=(x−2)²−1。顶点是 (2, −1)，x² 前系数为 1>0，开口向上。

x 轴交点：令 x²−4x+3=0，分解为 (x−1)(x−3)=0，得 x=1 或 x=3。图像经过 (1, 0) 和 (3, 0)。

值域：平方部分最小为 0，所以最小值 −1，值域 [−1, +∞)。

单调区间：在 (−∞, 2] 上递减，在 [2, +∞) 上递增。

检查点：顶点横坐标是否与配方里的 2 一致；两个根是否都写出；值域端点是否用方括号。

练习 2：两条限制取交集

练习 2 · 独立

求 f(x)=√(x+1)/(x−2) 的定义域

分别写出根号和分母的限制，再取同时满足的部分，用区间表示。

查看提示

根号内 x+1≥0；分母 x−2≠0。先在数轴上画出 x≥−1，再把 x=2 挖掉。

查看答案与解析

根号要求 x+1≥0，即 x≥−1；分母要求 x−2≠0，即 x≠2。两者同时满足：

[−1, 2) ∪ (2, +∞)

检查点：x=−1 时根号为 0，可以取，所以左端用方括号；x=2 时函数没有定义，所以 2 处用圆括号并把区间分成两段。

练习 3：整体代入

练习 3 · 找错与改正

f(x+1) 应该怎样算

某同学写：因为 f(x)=x²−2x，所以 f(x+1)=x²−2x+1。指出这一步错在哪里，并写出正确的 f(x+1)。

查看提示

把 x+1 看成一个整体，用括号包住，替换原来式子里的每个 x。替换完再展开、合并同类项。

查看答案与解析

错误：只在式子末尾加了 1，没有把 x+1 代进每个 x。f(x+1) 表示输入是 x+1，不是 f(x) 再加 1。

正确写法：f(x+1)=(x+1)²−2(x+1)=x²+2x+1−2x−2=x²−1。

检查点：两个 x 的位置是否都替换成了 x+1；展开 (x+1)² 时中间项 2x 是否写出；最后是否合并了同类项。

练习 4：图像整体平移

练习 4 · 迁移

把抛物线整体抬高 3 个单位

比较 f(x)=x²−2x 与 g(x)=x²−2x+3。写出 g 的顶点、值域，并说明它与 f 的图像位置关系；再判断 g 与 x 轴有没有交点。

查看提示

g(x)=(x²−2x)+3，先对括号内配方。比较两者的顶点纵坐标。判断与 x 轴交点时，看 g 的最小值是正、零还是负。

查看答案与解析

g(x)=x²−2x+3=(x−1)²−1+3=(x−1)²+2。顶点是 (1, 2)，开口向上，值域 [2, +∞)。

与 f(x)=(x−1)²−1 相比，每个输出都多了 3，图像整体向上平移 3 个单位，顶点从 (1, −1) 移到 (1, 2)。

g 的最小值是 2>0，图像整个在 x 轴上方，所以与 x 轴没有交点。代数上，方程 x²−2x+3=0 的判别式 Δ=(−2)²−4×1×3=4−12=−8<0，没有实数根。

检查点：配方是否得到 (x−1)²+2；值域是否为 [2, +∞)；是否用最小值正负判断了与 x 轴的无交点。

带走这个心智模型

函数是一条规则，图像是这条规则的全部输入—输出配对。定义域回答“哪些输入允许进入”，顶点和交点回答“图像的关键位置在哪里”，从左往右看回答“上升还是下降”。

下一课把“x 靠近某个数时 y 靠近什么”单独拿出来研究，那就是极限。今天先确保你能把 f(a) 算对、把定义域写对、把一张抛物线草图读对。
