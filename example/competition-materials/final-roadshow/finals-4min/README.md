# 学途智伴四分钟路演

当前主稿为2026年11月27日讲义融合版，16页、三章，纯口播768字。每段对应一页PPT备注，演讲稿与备注仅保留讲述内容。

主线：自学痛点 → Skill解决方案 → 教学闭环 → Python自适应对比 → 高数实际案例 → 持续学习价值。第3页用Python自学情境比较单次问答与课程闭环，第9页用列表索引说明不同表现对应的教学安排；高数案例按“访谈—评估—学习—续课”展开。

按4分钟排练：第1—11页约2分37秒，第12—15页配合60秒现场操作，第16页约23秒收束。正式汇报上限5分钟，专家问答另计2分钟。时间为排练预算，完整用时以本人计时为准。

同目录PPT可用WPS或PowerPoint打开，Word与Markdown讲稿可直接朗读。动作与切换步骤集中在“四分钟排练与现场操作表”，逐页预览和配图总览用于核对顺序。
