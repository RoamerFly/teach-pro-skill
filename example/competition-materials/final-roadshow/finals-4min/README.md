# 学途智伴四分钟路演

当前主稿为2026年11月27日四章目录版，共17页，纯口播795字。演讲稿每段对应一页PPT备注，均只保留讲述内容。

封面后第2页为目录导航，可点击章节标题跳转：设计初衷从第3页开始，工作流程从第7页开始，案例演示从第12页开始，结语为第17页。

第一章用Python自学情境说明学习中的断点，引出课程闭环与Skill封装。第二章解释课程Agent、课内AI和本地学情如何协作，再用Python列表展示自适应教学。第三章以高数实际课程串起访谈、评估、学习与续课。第四章回扣设计初衷与持续学习的价值。

按4分钟排练：第1—11页约2分33秒，第12页5秒引入案例，第13—16页配合60秒操作，第17页22秒收束。正式汇报上限5分钟，专家问答另计2分钟。完整用时以本人计时为准。

同目录PPT可用WPS或PowerPoint打开。Word与Markdown讲稿可直接朗读，动作与切换步骤集中在“四分钟排练与现场操作表”。

高数案例来自已核验的Codex实际调用Skill记录，学员为模拟大学生。

## 配色与视频入口

全稿以米色（#FAF7EF）为主背景，青绿色用于强调。

第12页“第三章 案例演示”的“打开演示视频”按钮指向同目录的“学途智伴高数60秒静音演示.mp4”。复制材料时将PPT与该视频放在同一文件夹；01_提前发送与02_现场使用均已配齐。

## 最终便携材料包

最终路演包包含现场课程、独立Windows x64 Python环境、PPT、讲稿与备用视频。完整解压后通过根目录“打开现场课程.cmd”启动。

本轮使用实际压缩包重新解压验证，四个启动入口、浏览器作答和重启恢复通过。验收脚本为仓库中的evals/check_finals_portable.py，浏览器检查为evals/check_finals_browser.mjs。
