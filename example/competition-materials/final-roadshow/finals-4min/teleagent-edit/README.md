# TeleAgent 高数学习闭环录屏

这段60秒静音视频记录学途智伴在TeleAgent 3.1.1中的实际运行。模拟学员是一位高数基础薄弱、每周学习3至5小时、偏好图解和例题的大学新生。

## 演示流程

| 阶段 | 实际操作与结果 |
| --- | --- |
| 提出目标 | 在TeleAgent输入“我想学习大学课程：高等数学”，由Skill主动发起访谈 |
| 形成课程 | 访谈后生成课程路线、入门评估和第一课网页 |
| 学习作答 | 打开网页完成评估、阅读函数图解、做即时检查并填写练习与疑问 |
| 依据作答续课 | 回到TeleAgent请求继续，由Agent读取自动保存的作答 |
| 两种教学安排 | 生成“图像平移”关联补充课，同时交付“极限的直觉”正式第二课 |
| 连接课内AI | 在课程设置中选择DeepSeek，遮蔽输入密钥，获取模型并测试连接 |
| 连贯答疑 | 使用DeepSeek Flash实际回答平移问题，再追问括号内加2的顶点变化 |

本次作答包含一处连贯的理解偏差：将函数式末尾加3当成向右平移。补充课据此比较`f(x)+3`与`f(x−3)`；正式课继续推进极限的新目标。

## 剪辑与复现

长时间生成等待已剪去，操作镜头以1.15至1.3倍适度加速，图解与回答保留阅读时间，总长60秒。阶段标题置于画面外侧。录屏画面来自TeleAgent和课程网页，学员身份为模拟。

课内AI为真实模型调用，回答引用了学员写下的顶点和已生成的补充课，并完成第二轮追问。密钥输入框始终保持密码模式。

`timeline.json`保存每段来源、时间与裁剪范围；`render.py`按时间线导出1920×1080、24帧的MP4。原始录屏和学员作答保存在项目工作目录，仓库记录来源校验和验证结果。

运行时为脚本指定原始素材目录、输出位置、FFmpeg及中文字体路径：

```text
python render.py --raw-dir <原始素材目录> --output <输出.mp4> --ffmpeg <ffmpeg可执行文件> --font <中文字体文件>
```
