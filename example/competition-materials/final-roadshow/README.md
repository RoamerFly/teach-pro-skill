# 学途智伴决赛路演十页三章版

## 文件

- 学途智伴决赛路演_8分钟.pptx 为可编辑PPT，10页备注仅包含对应页的口播正文。
- 学途智伴决赛演讲稿_8分钟.docx 为1页口播稿，Markdown版便于修改。两版只保留口播正文，每段对应一页PPT。
- 学途智伴课程演示_60秒.mp4 在第8页切换播放，同步现场解说。
- 路演配图总览.jpg 为当前10页预览，逐页预览目录保存各页图片。

## 制作与检查

build_deck_v4.mjs 为当前10页版构建入口。export_local_pptx.mjs 接收运行库目录和输出路径。build_speech.py 从路演内容.json 生成两种讲稿。

已检查10页结构、演讲者备注与讲稿一致性、包完整性、布局几何和Artifact Tool导入，并渲染检查10页画面与1页讲稿。4分20秒为排练安排，实际用时以本人完整排练为准。

当前高数案例以 f(x)=x³ 在 x=0 处无极值，与 g(x)=x³−3x 在 x=1 处有极小值作对照。根据学生能否结合导数符号解释结论，展示补充讲解和应用任务的教学安排。
