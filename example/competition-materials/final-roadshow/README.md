# 学途智伴决赛路演 8分钟版

当前版本为十二页定制配图版，12页，一人主讲。精简口播共1185个字符，按6分15秒排练，含一分钟操作演示。

## 打开与排练

1. 用WPS或PowerPoint打开[本地PPT](学途智伴决赛路演_8分钟.pptx)。文字、流程图和排序示意图可编辑，12页备注与完整讲稿同步。
2. 对照[完整演讲稿](学途智伴决赛演讲稿_8分钟.docx)讲解，也可编辑[Markdown稿](学途智伴决赛演讲稿_8分钟.md)。每页附有累计时间和动作提示。
3. 第8页引入约5秒后，切换播放[60秒操作片段](学途智伴课程演示_60秒.mp4)，同时现场解说。播放结束返回第8页，收束约5秒后进入第9页。

PPT里的完整操作演示链接用于备用。现场主流程使用本目录60秒片段。初版已保留在本地“历史版本/2026-11-17-初版”目录，当前排练使用本目录的新版PPT。

## 讲述顺序

设计初衷引出学习期待，使用旅程解释学生怎样开始，协作架构交代Skill怎样连接教学、课堂和记录。随后分别解释跨会话接续、依据作答调整教学、正式课与补充课协同，配合操作演示、统计学案例与校园应用完成讲述。

12页分别使用GPT内置生图制作的独立图片，对应Skill交付、学习初衷、使用旅程、协作架构、学习记录、自适应教学、正式课与补充课、操作演示、统计学案例、验证路径、校园应用和收束。图解标题、连接线、统计学数值和备注保留为原生可编辑元素，第8页嵌入真实答疑截图。

[查看12页整体预览](路演配图总览.jpg)，[查看逐页图片及生成提示词](assets/per-slide/README.md)。本地“逐页预览”目录提供每页最终渲染。
