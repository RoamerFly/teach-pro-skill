# 学途智伴决赛路演十页三章版

当前版共10页，包含封面、三张章节页与收尾页。口播正文569个字符，一页Word，计划约3分52秒。实际时间以本人排练为准。

## 本地排练

打开学途智伴决赛路演_8分钟.pptx，十页备注均为对应页实际口播。Word与Markdown同样只保留口播正文，每段对应一页。

第7至9页讲高等数学零基础实际运行案例，按对话、首课与作答后续课依次介绍。第7页采用实际对话原文排版的记录截图，第8、9页采用实际课程网页截图。截图保存在assets/calculus-run，原始生成课程在example/competition-demo-calculus。

## 十页结构

1. 封面
2. 第一章 设计初衷
3. 从目标到第一课
4. 第二章 教学机制
5. Skill协作架构与课程记录
6. 作答决定支持方式
7. 第三章 演示与价值，展示零基础学生的实际对话
8. 从一句需求到第一课
9. 学生作答怎样改变后续课程
10. 应用场景与收尾

## 案例来源

通过Codex CLI实际调用仓库Teach Pro，四轮对话串行执行。模拟大一学生在浏览器中填写入门评估和首课练习，验证保存及刷新恢复，教学Agent读取原始提交，交付两节正式课与一节关联补充课。实际对话、运行来源与学习记录随案例保存，原始提交文件与事件日志保存在本地测试目录。

当前路演使用截图讲解。目录中的60秒智鉴Agent录像保留供参考。
