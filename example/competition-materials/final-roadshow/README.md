# 学途智伴决赛路演十六页三章版

当前为完整讲述版，共16页，包含封面、三张章节页与收尾页。口播正文536个字符，一页Word。内容页补充了可直接朗读的完整句子，按页面顺序即可讲清动机、使用流程、教学机制与真实案例。每页备注仍为精简口播，每段与一页PPT对应。文件沿用“8分钟版”目录入口。

## 文件与排练

学途智伴决赛路演_8分钟.pptx为可编辑PPT，Word与Markdown演讲稿均可直接朗读。路演配图总览.jpg提供16页整体预览，逐页预览目录提供各页画面。

## 第一章 设计初衷

第2页为章节页，第3页讲设计初衷，第4页讲学生使用流程，第5页说明Skill技能包的交付组成。

## 第二章 教学机制

第6页为章节页，第7页讲教学AI、网页与工作区协作，第8页讲跨会话学情接续，第9页讲依据作答调整教学，第10页讲正式课和补充课。

## 第三章 演示与价值

第11页为章节页，第12页展示模拟零基础新生与Agent的实际对话原文记录，第13页展示网页评估与起点判断，第14页展示首课图解与教学组件，第15页展示作答后的真实续课目录。第16页收束用途和价值。

本轮实际使用Codex CLI调用Teach Pro，四轮对话串行执行。课程产物为两节正式课和一节关联补充课。原始生成课程与实际对话在example/competition-demo-calculus，截图在assets/calculus-run。对话图为实际执行原文的记录页排版，课程图为浏览器实截。
