# 学途智伴决赛演讲稿编写方案

方案日期为2026年11月17日，与[决赛路演详细方案](决赛路演详细方案.md)配套。当前按一人主讲、8分钟工作版编排，正式时长收到后统一调整。

## 讲述方式

全场先讲设计初衷，再用学生的一次学习过程说明学途智伴的用途。开场在20秒内说出“学途智伴是一个自适应教学Skill技能包”，第2页以45秒讲清为什么设计它，随后围绕起点、教学、作答、答疑和续课展开。每个创新机制先讲它帮助学生完成什么，再用一幅图或一个操作解释怎样实现。

主讲以自然交流的语气讲清因果。介绍作品时可使用“我带来的学途智伴”，现场操作时使用“我在这里写下这段回答”。讲授与评委交流保持正常语速，图解、对照和结果出现时留出观察时间。

工作版预计讲稿约1450—1650字。时间安排包含看图、视频播放和翻页，录屏段由本人配合画面讲解。先试讲并实测总时长，再调整字数与停顿。演讲稿采用逐页段落，在相应位置标注翻页、播放和指图动作。

## 开场试讲段落

各位评委好，我带来的学途智伴，是面向大学生长期学习的自适应教学Skill技能包。学生告诉AI想学什么，完成评估后开始逐课学习。自己的回答和疑问会留在课程里，成为下一次教学的依据。

这段开场完成作品定位，随后进入设计初衷，再展开学生场景。正式比赛名称、学院和主讲姓名按用户提供的信息补齐。

## 设计初衷试讲段落

依据作者2026年11月17日补充的真实设计初衷整理，用于第2页约45秒的口述。

设计学途智伴的起点，是想把AI快速获取资料的能力，变成一段系统的学习过程。我希望有一位学习私教，先了解我的基础，逐课讲解，再根据练习和疑问调整下一课。因此，我把这套方法做成Skill，直接生成课程网页，把讲解、习题、资料和随时答疑放在一起。学生在学习中留下的回答和提问，帮助AI了解学情，接着实际进度继续教。

这段先说明资源获取与系统学习的关系，再解释网页怎样承载学习活动和学情记录，最后连接动态安排课程这一学习私教体验。正式稿根据实际朗读和画面停留微调。

## 三个机制的口语解释草案

### 学习记录接续教学

学生的学习目标、当前路线、每道题的回答和课末疑难，都保存在课程工作区。过一段时间回来，学生提出“继续下一课”，教学AI就能读取当前记录，知道上一次学到了哪里、哪些问题需要继续解释，再安排新课。学生可以把精力放在理解和练习上。

### 作答影响教学支持

我们看学生怎样解释、怎样应用。比如在两组统计学作答案例中，一份回答还能说清新增数据后中间位置为什么变化，另一份需要继续理解排序位置。教学AI会据此选择迁移练习，或者提供逐步的计算支持。同一目标，可以有适合当前理解程度的讲法。

### 正式课和补充课共同推进

正式课围绕一个新的学习目标提供完整讲解、示范和练习。上一课出现的具体疑问，可以在同一轮获得一节关联补充课。学生一边沿主线学习，一边补上相应解释，两类课程各自保存作答，方便后续继续调整。

这些段落用于确定语气和解释方式，正式稿随PPT图示压缩到各页预算。

## 结尾试讲段落

回到最初的愿望，我希望AI能把资料组织成系统学习，并像学习私教一样，接着学生的实际进度继续教。学途智伴以Skill交付，把课程、作答和答疑连接起来，让后续教学有据可循。我的介绍结束，欢迎各位评委提问。

## 去防御化表达的具体做法

| 要讲的内容 | 建议口语 |
| --- | --- |
| 作品定位 | 学途智伴以Skill技能包交付，导入后按学习目标组织教学。 |
| 课程进度 | 教学AI结合学生的解释和应用表现安排下一步。 |
| 长期记忆 | 学习目标、路线和作答保存在工作区，新会话读取后继续教学。 |

主讲按“用途→机制→操作或案例→学生得到的帮助”解释。数字、来源和案例名称与对应材料一致。页面文字直接说学习与使用，讲稿展开实现原因。

## 问答组织

回答先给结论，再用一项具体机制或案例展开，通常控制在30—45秒。评委追问时打开相应附页。

| 问题 | 回答主线 |
| --- | --- |
| 为什么采用Skill技能包 | 教学方法可随包复用，模板和工具保证课程具备阅读、作答、保存与答疑入口，宿主教学AI按规则生成与续课。 |
| 自适应体现在哪里 | 回答中的推理影响目标、讲法和支持程度，用统计学两组作答及关联补充课展示。 |

| 如何面向不同学科 | 学习使命、评估、讲解和反馈规则共同复用，课程内容和图解随主题变化，现有Agent与统计学案例可展示。 |
| 怎么了解实际使用效果 | 现有材料记录课程交付、保存恢复和交互结果，后续试用继续记录学习任务完成情况与学习体验。 |

## 稿件制作和排练

第一轮先完成逐页主讲稿，将每页控制在一个核心结论。第二轮对照实际画面补齐指图、播放、停顿和翻页动作。第三轮本人完整试讲，记录每页和总时长，再调整句子与演示节奏。

工作稿用“〔翻页〕”“〔播放〕”“〔指图〕”“〔停顿〕”标记动作，最终同时保留带动作提示的排练稿和便于阅读的讲稿。视频片段播放与现场操作纳入每次全程计时。

5分钟版合并案例和机制解释，保留Skill定位、学习闭环、作答影响教学以及操作结果。10分钟版增加一个统计学对照细节、一段教学设计解释和操作停留时间。

后续交付包括逐页主讲稿、带计时的排练稿和对应PPT附页。正式时长、模板及主讲信息确认后形成提交版。
