# 学途智伴演示视频方案

队伍：重邮FFBond。作品：学途智伴——大学生长期自适应学习智能体。

本版围绕一个大学生的学习过程展开，成片 168.46 秒，约 2 分 48 秒。教师保留用户选定的 A 女声，学生保留 Andre 男声；十三个镜头按学习需要衔接，不再逐项报功能。准确时间码见 `dialogue-video-chapters.json`，历史版本保留在 Git 中。

台词以 `dialogue-plan.json` 为唯一来源。先合成讲解、测量每句时间，再按口播节奏实录操作；两轮答疑录制后，才合成实际返回的答案。音色、按句情感、语速与时长见 `audio/dialogue-voice-audit.json`。

## 讲解主线

同学想做安全情报智能体，却不知道起点。教师先介绍 Skill 的调用方式，再用评估了解基础。第一课从消息图解进入代码，课内论文与视频承接深入学习的需求。

同学在代码里发现“这次请求只带这次消息”，由此问出“模型还记得上一轮吗”。教师肯定这个问题，打开课内答疑；页面提示连接模型，才进入 DeepSeek 设置。连接成功后返回同一课答疑窗口，继续刚才的问题。首轮回答解释上下文，第二轮从这个解释自然追问“有历史就是 Agent 吗”。

同学用自己的话总结后，教师让他把解释和疑难写进学习记录。接着展示回到 TeleAgent 读取记录的续课提示词，最后回放正式课与补充课的已有结果。每一步都回应上一步产生的需求。

学途智伴的交付物是 `teach-pro` Skill 技能包，包含教学规则、配套规范、网页模板和本地工具。TeleAgent 调用技能并生成、续写课程；智鉴课程是本次案例；浏览器答疑辅助理解当前课。

导入后展示的调用示例：`@teach-pro 我想系统学习智能体开发与安全，有 Python 基础，会调用大模型 API，但没有 Agent 项目经验。每周能学五小时，目标是独立开发安全情报 Agent。先评估我的基础再开课。`

学完一课后回到 TeleAgent 请求续课，教学 AI 读取本地答案和疑难再作教学决策；浏览器答疑模型负责解释当前课的问题。本轮开场展示包组成与调用方式示意，课堂操作真实录制，续课展示已有结果回放；没有把画板或页面切换包装成新的 TeleAgent 执行。

## 真实问答录制

首问：为什么第二次只发新问题，就不知道上一轮的信息？结合本课的 messages 代码，用不超过 65 字的一段话解释，不写代码。

追问：那把历史 messages 带上，就算 Agent 了吗？接着刚才的解释，用不超过 65 字区分多轮聊天和工具型 Agent，不写代码。

本轮实际模型列表包含 `deepseek-flash`，获取、保存、测试与两轮问答均成功。密钥输入框保持 password，不点击小眼睛；本机凭据实际保存后，在录制结束删除隔离课程的临时凭据。

两轮完整原始回答与请求诊断保存在隔离工作区。教师朗读实际答案，仅去除 Markdown 标记；录制同时核验回答完成、问题配对、上下文延续与增量显示。

本轮四次真实提供商请求：模型列表、连接测试、首问、追问。保存设置为本地操作。原始回答与诊断保存在仓库外隔离工作区；公开章节记录只保留去敏的状态与哈希。续课使用已生成结果回放。

## 配音与字幕

教师保留用户选定的 A：百炼 MiniMax Speech 2.8 HD“阅历姐姐”。每句按用途处理，原生语速为 1.24–1.30：接住提问、连接成功和肯定理解用 happy，机制解释用 calm，其他句子随正文匹配情感。台词减少长串功能罗列，使用“问得好”“对”“没错”等接话，把引导、解释和鼓励分开。

学生保留 Andre / Qwen3-TTS-Flash 沉稳男声，重写七段台词：求教、好奇、发现疑点、求证、领悟后追问、总结和期待。通过“欸”“哦”“明白了”及自然问句改变表达节奏，不朗读舞台指示。该音色不支持独立情感指令；计划里的 `delivery` 记录表演意图，不发送给模型。

两角色不作后期变速或变调，混音只统一响度。字幕按实测片段重排；口播之后保留短停顿，模型实际返回后才朗读答案。设置与两轮答疑有最低观看时间。整片听感、术语发音和逐句字幕同步仍需试看。

协议与音色范围见[MiniMax 同步语音合成](https://help.aliyun.com/zh/model-studio/minimax-synchronous-speech-synthesis-api)、[Qwen 音色列表](https://help.aliyun.com/zh/model-studio/qwen-tts-voice-list)。当前是合成配音，不标成真人录制。此前 Qwen 女声和本次未选中的 HD 候选保留作历史对照，当前师生版不使用它们。

旧 `audio/连续旁白候选.mp3`、男女声试样和 `audio/旁白字幕候选.srt` 保留作历史对照，不适配本版新正文。完整配音更新后重新生成字幕；成片插入等待或阅读停顿后再次对齐。

字幕使用画面之外的紧凑底条，不覆盖图解、设置或输入。真实操作按原速连续保留，只裁掉动作完成后的尾部空等；不再用“开头加结尾”的剪法跳过镜头中段。导入与续课提示词标注示意，已有课程结果标注回放。成片不超过 180 秒。
