队伍：重邮FFBond。作品：学途智伴——大学生长期自适应学习智能体。

本版围绕一个大学生的学习过程展开，成片 170.74 秒，约 2 分 51 秒。教师保留用户选定的 A 女声，学生采用温润、磁性的青年男声；十三个镜头按学习需要衔接。准确时间码见 `dialogue-video-chapters.json`，历史版本保留在 Git 中。

原台词来源为 `dialogue-plan.json`，本次实际台词与情感参数见 `emotional-performance-plan.json`。2026-10-26 本次将评估、图解、资源、模型设置、返回课程、两轮答疑、作答和续课结果全部重录为 rc.16 界面。模型与思考程度选择、紧凑输入区、消息复制与修改等操作入口随真实学习流程展示。开场保留已确认的工作流程架构图。

已录制的两轮真实 DeepSeek 回答经哈希校验后，在新版 HTTP/SSE 答疑组件中回放；朗读与回答逐字对应。本次师生全部32个片段重新通过百炼 MiniMax Speech 2.8 HD 合成，按对话功能分段设置情感和原生语速，字幕按新音频时长重新编排。课程画面按新表演时点录制；开场、学习主线与总时长保持完整。当前制作工具为 `regenerate_expressive_voice.py`、`refresh_rc16_capture.cjs` 和 `render_expressive_video.py`。
原录制先合成讲解、测量每句时间，再按口播节奏实录操作；两轮答疑录制后，才合成实际返回的答案。音色、按句情感、语速与时长见 `audio/dialogue-voice-audit.json`。

## 讲解主线

同学想做安全情报智能体，却不知道起点。教师借架构图先介绍 Skill 与学习闭环：访谈和评估确定起点，作答与疑难保存到本地，请求继续时由教学 AI 读取记录。接着进入入门评估。第一课从消息图解进入代码，课内论文与视频承接深入学习的需求。

同学在代码里发现“这次请求只带这次消息”，由此问出“模型还记得上一轮吗”。教师肯定这个问题，打开课内答疑；页面提示连接模型，才进入 DeepSeek 设置。连接成功后返回同一课答疑窗口，继续刚才的问题。首轮回答解释上下文，第二轮从这个解释自然追问“有历史就是 Agent 吗”。

同学用自己的话总结后，在每道题后直接填写解释，在课末记录疑难。接着展示回到 TeleAgent 读取记录的续课提示词，最后回放正式课与补充课的已有结果。每一步都回应上一步产生的需求。

学途智伴的交付物是 `teach-pro` Skill 技能包，包含教学规则、配套规范、网页模板和本地工具。TeleAgent 调用技能并生成、续写课程；智鉴课程是本次案例；浏览器答疑带入整门已生成教材，并标明当前提问课与选文出处。

导入后展示的调用示例：`@teach-pro 我想系统学习智能体开发与安全，有 Python 基础，会调用大模型 API，但没有 Agent 项目经验。每周能学五小时，目标是独立开发安全情报 Agent。先评估我的基础再开课。`

学完一课后回到 TeleAgent 请求续课，教学 AI 读取本地答案和疑难再作教学决策；浏览器答疑模型结合教材和本课对话解释问题。架构开场介绍系统分工，真实课堂操作展示使用流程，续课结果呈现主线推进和难点巩固。

## 已录制真实问答与新版界面回放

首问：为什么第二次只发新问题，就不知道上一轮的信息？结合本课的 messages 代码，用不超过 65 字的一段话解释，不写代码。

追问：那把历史 messages 带上，就算 Agent 了吗？接着刚才的解释，用不超过 65 字区分多轮聊天和工具型 Agent，不写代码。

原录制实际模型列表包含 `deepseek-flash`，获取、保存、测试与两轮问答均成功。密钥输入框保持 password，不点击小眼睛；本机凭据实际保存后，在录制结束删除隔离课程的临时凭据。

两轮完整原始回答与请求诊断保存在隔离工作区。教师朗读实际答案，仅去除 Markdown 标记；原录制核验回答完成、问题配对、上下文延续与增量显示。当前界面回放继续使用相同的两个问题和原始回答，不新增模型答案或思考内容。

原录制四次真实提供商请求：模型列表、连接测试、首问、追问。保存设置为本地操作。原始回答与诊断保存在仓库外隔离工作区；公开章节记录只保留去敏的状态与哈希。续课使用已生成结果回放。

## 配音与字幕

教师使用 A：“阅历姐姐” / MiniMax Speech 2.8 HD，保留成熟教师女声。短接话与鼓励单独合成，使用 happy；观察问题时带轻微惊讶与提问起伏；机制解释由模型自动选择情绪。原生语速1.27–1.30，简短回应与较长解释之间保留约120毫秒自然停顿。

学生使用“温润男声” / MiniMax Speech 2.8 HD，保持青年男性温润、沉稳的声音方向。发现疑点和追问使用 surprised，领悟和期待使用 happy，开场求教由模型随台词自动表达；原生语速1.19。

全部台词重新合成，实际模型答案只去掉 Markdown 标记。说明性台词调整为自然口语，师生换人间隔约250毫秒；后期仅统一响度，不做倍速或变调。新字幕按每个语音片段实测时长与短句切分重排，保留画面下方的紧凑字幕条。

情感、语速、时长和哈希见 `audio/dialogue-voice-audit.json`。接口参考：[MiniMax 同步语音合成](https://help.aliyun.com/zh/model-studio/minimax-synchronous-speech-synthesis-api)。
