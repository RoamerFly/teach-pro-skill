# 学途智伴演示视频方案

队伍：重邮FFBond。作品：学途智伴——大学生长期自适应学习智能体。

师生版从 Skill 技能包的定位与调用开始，再演示生成的课程、可选答疑和基于记录的续课。首版成片约 175.14 秒，详见 `dialogue-video-chapters.json`。旧单人旁白的 156.41 秒不适配本版。

师生版解说以 `dialogue-plan.json` 为唯一来源，两轮教师答疑使用 DeepSeek 实际返回的原文，仅去除 Markdown 标记；实际口播、音色和语音片段时长保存在 `audio/dialogue-voice-audit.json`。下表为原分镜预算，准确章节以实测记录为准；声音未加速。

## 讲解主线

学途智伴的交付物是 `teach-pro` Skill 技能包，包含 `SKILL.md` 教学规则、配套规范、网页模板和本地工具。TeleAgent 是调用技能、生成及续写课程的宿主；智鉴课程是本次演示的生成作品；浏览器中的课内答疑是课程的可选辅助功能。开场展示技能包与调用，再进入课程页面，让观众先知道作品是什么、怎样用。

导入后展示的调用示例：`@teach-pro 我想系统学习智能体开发与安全，有 Python 基础，会调用大模型 API，但没有 Agent 项目经验。每周能学五小时，目标是独立开发安全情报 Agent。先评估我的基础再开课。`

学完一课后回到 TeleAgent 请求续课，教学 AI 读取本地答案和疑难再作教学决策；浏览器答疑模型负责解释当前课的问题。本轮开场展示包组成与调用方式示意，课堂操作真实录制，续课展示已有结果回放；没有把画板或页面切换包装成新的 TeleAgent 执行。

## 真实问答录制

首问：为什么第二次只发新问题，就不知道上一轮的信息？结合本课的 messages 代码，用不超过 65 字的一段话解释，不写代码。

追问：那把历史 messages 带上，就算 Agent 了吗？接着刚才的解释，用不超过 65 字区分多轮聊天和工具型 Agent，不写代码。

本轮实际模型列表包含 `deepseek-flash`，获取、保存、测试与两轮问答均成功。密钥输入框保持 password，不点击小眼睛；本机凭据实际保存后，在录制结束删除隔离课程的临时凭据。

保留完整原始回答和请求诊断。若回答冗长，只在镜头中选取相关段落，不替换回答；若接口失败，保留失败诊断，修正配置后重新录制，不能剪出虚假成功。当前方案为两轮真实答疑，减少请求和等待，同时展示上下文延续。

本轮四次真实提供商请求：模型列表、连接测试、首问、追问。保存设置为本地操作。原始回答与诊断保存在仓库外隔离工作区；公开章节记录只保留去敏的状态与哈希。续课使用已生成结果回放。

## 配音与字幕

学生采用 Andre 沉稳男声，提出学习目标和两次疑问。教师采用 Elias 讲师女声，使用成熟、沉着、亲切的教师语气指令，讲操作与机制；两轮答疑朗读实际模型回答。角色音色保持一致，转换时留短停顿。英文术语统一读法，语速保持自然，片段衔接与主观听感仍需试看确认。

官方音色及模型兼容范围见[百炼音色列表](https://help.aliyun.com/zh/model-studio/qwen-tts-voice-list)。当前是情感型合成配音，不标成真人录制。之前的“亲切讲解”“同学分享”女声对照试样保留历史用途，师生版不使用它们。

旧 `audio/连续旁白候选.mp3`、男女声试样和 `audio/旁白字幕候选.srt` 保留作历史对照，不适配本版新正文。完整配音更新后重新生成字幕；成片插入等待或阅读停顿后再次对齐。

字幕最多两行，用画面之外的紧凑底条；教学画面固定保留足够高度，字幕不覆盖图解、密钥框或输入。剪辑可以去掉无操作等待，但实际接口关键状态应保留；需要加速或回放时明确标注。真实问答录制本身不受计划时长限制，成片须重新测量至 180 秒以内。

## 成片检查

逐镜检查：密钥没有显示、模型名称与接口一致、答疑真实且多轮、课程回放有标记、合成输入未冒充真人成绩、字幕与正文不重叠、音画同步、术语发音一致。完整解码成片，并核查音轨、总时长和所有章节代表帧。通过后才替换旧版提交候选。
