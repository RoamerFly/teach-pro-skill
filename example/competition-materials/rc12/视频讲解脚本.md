# 学途智伴演示视频方案

队伍：重邮FFBond。作品：学途智伴——大学生长期自适应学习智能体。

本版从 Skill 技能包的定位与调用开始，再演示它生成的课程、可选答疑和基于记录的续课。成片预算约 170 秒，最终必须小于 180 秒。本文件是新版录制方案，完整配音和成片尚未重制；旧连续旁白的 156.41 秒不代表本版时长。

旁白正文以 `video-scenes.json` 为唯一来源。下表时间是镜头预算，须依据新版实测配音和操作录像重新分配，不通过加速旁白压缩时长。

## 讲解主线

学途智伴的交付物是 `teach-pro` Skill 技能包，包含 `SKILL.md` 教学规则、配套规范、网页模板和本地工具。TeleAgent 是调用技能、生成及续写课程的宿主；智鉴课程是本次演示的生成作品；浏览器中的课内答疑是课程的可选辅助功能。开场展示技能包与调用，再进入课程页面，让观众先知道作品是什么、怎样用。

导入后展示的调用示例：`@teach-pro 我想系统学习智能体开发与安全，有 Python 基础，会调用大模型 API，但没有 Agent 项目经验。每周能学五小时，目标是独立开发安全情报 Agent。先评估我的基础再开课。`

学完一课后回到 TeleAgent 请求续课，教学 AI 读取本地答案和疑难再作教学决策；浏览器答疑模型负责解释当前课的问题。两段操作分别展示。

## 真实问答录制

首问：本课里，第二次 API 请求只传新问题，为什么不能知道第一轮提过的信息？结合本课的 messages 代码解释，用一个小例子。

追问：那我把历史 messages 带上，就算 Agent 了吗？请接着刚才的例子，区分多轮聊天和工具型 Agent。

录制前确认模型列表真实包含所选模型 ID，再决定口播名称；`video-scenes.json` 的 `deepseek-flash` 是计划值，不是已验证结果。成功画面必须来自模型获取、保存与测试的实际结果。不得把无效示例密钥截图或合成接口用于这一段。密钥输入框一直保持 password 状态，不点击显示小眼睛。

保留完整原始回答和请求诊断。若回答冗长，只在镜头中选取相关段落，不替换回答；若接口失败，保留失败诊断，修正配置后重新录制，不能剪出虚假成功。当前方案为两轮真实答疑，减少请求和等待，同时展示上下文延续。

预计四次提供商请求：获取模型列表、测试连接、首问、追问。保存设置是本地操作，不算模型请求。凭据与聊天保存在录制工作目录，公开材料只记录去敏后的结果。设备记忆的展示须以真实凭据保存结果为准。教学智能体续课使用已生成结果回放，不把镜头切换包装成实时生成。

## 配音与字幕

按整个故事录制连续旁白，不把每个按钮读成孤立命令。语气像向同学介绍自己的作品：速度平稳，概念前轻停顿，重要对比稍慢，不夸张拔高、不连续念宣传词。英文术语先统一读法；API 逐字母，DeepSeek 使用一致读法，Agent 在解释句中说智能体。

新版开场用百炼 Qwen 指令型合成语音制作“亲切讲解”和“同学分享”两种试样，口播和指令维护在 `expressive-voice-plan.json`，实际产物及检查状态见 `audio/expressive-voice-audit.json`。音色与术语读法须试听确认；技术检查不能代替听感。确定语气后再重制完整旁白，连续音轨避免逐镜重启语气断裂，不通过加速掩盖时长超限。

旧 `audio/连续旁白候选.mp3`、男女声试样和 `audio/旁白字幕候选.srt` 保留作历史对照，不适配本版新正文。完整配音更新后重新生成字幕；成片插入等待或阅读停顿后再次对齐。

字幕最多两行，用画面之外的紧凑底条；教学画面固定保留足够高度，字幕不覆盖图解、密钥框或输入。剪辑可以去掉无操作等待，但实际接口关键状态应保留；需要加速或回放时明确标注。真实问答录制本身不受计划时长限制，成片须重新测量至 180 秒以内。

## 成片检查

逐镜检查：密钥没有显示、模型名称与接口一致、答疑真实且多轮、课程回放有标记、合成输入未冒充真人成绩、字幕与正文不重叠、音画同步、术语发音一致。完整解码成片，并核查音轨、总时长和所有章节代表帧。通过后才替换旧版提交候选。
