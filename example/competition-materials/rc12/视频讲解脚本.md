# 学途智伴演示视频方案

队伍：重邮FFBond。作品：学途智伴——大学生长期自适应学习智能体。

目标时长 175 秒，预留 5 秒余量；实际成片按旁白与接口响应复测。本文件是录制方案，不是已完成的视频。

## 真实问答录制

首问：本课里，第二次 API 请求只传新问题，为什么不能知道第一轮提过的信息？结合本课的 messages 代码解释，用一个小例子。

追问：那我把历史 messages 带上，就算 Agent 了吗？请接着刚才的例子，区分多轮聊天和工具型 Agent。

录制前确认模型列表真实包含所选模型 ID，再决定口播名称；不硬编码模型可用性。成功画面必须来自模型获取、保存与测试的实际结果。不得把无效示例密钥截图或合成接口用于这一段。

保留完整原始回答和请求诊断。若回答冗长，只在镜头中选取相关段落，不替换回答；若接口失败，保留失败诊断，修正配置后重新录制，不能剪出虚假成功。当前方案为两轮真实答疑，减少请求和等待，同时展示上下文延续。

## 配音与字幕

按整个故事录制连续旁白，不把每个按钮读成孤立命令。语气像向同学介绍自己的作品：速度平稳，概念前轻停顿，重要对比稍慢，不夸张拔高、不连续念宣传词。英文术语先统一读法；API 逐字母，DeepSeek 使用一致读法，Agent 在解释句中说智能体。

先为开场、配置和问答各试一小段，听清停顿、句尾和术语后再做完整音轨。保持音频原始速度；镜头配合语句调整，不通过加速掩盖时长超限。自然合成配音不标成真人录制。

字幕最多两行，用画面之外的紧凑底条；教学画面固定保留足够高度，字幕不覆盖图解、密钥框或输入。剪辑可以去掉无操作等待，但实际接口关键状态应保留；需要加速或回放时明确标注。真实问答录制本身不受计划时长限制，成片须重新测量至 180 秒以内。

## 成片检查

逐镜检查：密钥没有显示、模型名称与接口一致、答疑真实且多轮、课程回放有标记、合成输入未冒充真人成绩、字幕与正文不重叠、音画同步、术语发音一致。完整解码成片，并核查音轨、总时长和所有章节代表帧。通过后才替换旧版提交候选。
