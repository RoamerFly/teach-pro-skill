# Mission: 智鉴 Agent

本文件描述虚构演示学习场景，不是实际学员画像。

## Why

理解并实现可核查、受控的 AI 安全情报 Agent，把情报搜集、整理与报告输出接进有边界的执行流程。

## Success looks like

- 画出模型、外部数据、工具执行与信任边界，解释每层职责。
- 实现最小消息与工具循环，处理拒绝、异常与停止。
- 完成使用获准数据源的情报项目，并用正常/拒绝案例检验，而非仅展示一条成功输出。

## Deadline or horizon

演示场景无固定学习截止；分阶段按作品与表现推进。

## Constraints

- 时间：演示设定每周约五小时。
- 基础：演示设定基本 Python、使用过模型 API、无 Agent 项目经验，均非能力测量。
- 表示：图解与理解优先，代码和推导其次，项目再次。
- 语言：中文；英文材料提供精确短片段任务。
- 工具：阅读不依赖网络；模拟练习无真实外发，实际 API 与项目环境按需验证。

## Out of scope for now

不先堆多个框架或完整项目；先建立消息、决策与执行边界。
