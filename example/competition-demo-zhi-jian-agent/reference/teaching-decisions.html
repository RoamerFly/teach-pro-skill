不是下一页，而是下一步

已观察到的差别不是换了标题，而是教学任务从“收集证据”变为“修正具体推理”，再变为“教新目标”。

以下为合成场景摘要，不展示原始学员答案；页面课程经人工校核。回放不是实时模型运行。

三种教学选择

输入情况观察到的判断交付任务
关键开放题没有足够内容无法据“读完了”判断理解交付巩固课，收集解释与迁移证据
把公告外观与外发授权混淆定位来源可信与动作权限的混淆先答疑，再交付信任边界补救课
新合成内容能区分身份、任务、目标和内容当前内容支持进入工具调用教学回答连接疑问，交付工具数据流推进课

前两条来自第一课后的隔离分支；第三条是在人工修订的补救课后提供合成即时答案。它们不是同一真实学员的连续成绩。

本地学习闭环

  1. 学员：阅读当前课，填写解释、练习与疑难。
  2. 本地服务：自动写入 learner-submissions；静态打开时只存浏览器副本。
  3. 课程生成 AI：用户请求继续后，读取当前课程文件，先处理疑难，再选择一节课。
  4. 课程工作区：新增一课并更新首页、路线和证据记录；下一目标仍待作答决定。

可选课内 Tutor 负责当前课问答；不替代课程生成 AI，不自行写下一课。

证据范围

  • TeleAgent v2.5.2；界面模型选项为“旗舰模型”，底层型号及实际导入指纹未知。
  • 三种选课决策已观察；原生课文仍有内容和状态缺陷，展示课已人工修订。
  • 本副本使用 rc.3 运行资产，没有预置你的答案、聊天、密钥或掌握率。
  • 这些观察不证明长期学习效果、跨学科泛化或完全无人工干预的教学闭环。
