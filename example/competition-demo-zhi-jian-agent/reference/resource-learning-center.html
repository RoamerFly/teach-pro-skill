01 · 调用与循环

优先 · DeepSeek《首次调用 API》

读“调用对话 API”的 Python 样例，约 10 分钟。找出地址、模型、messages 与取结果的位置；将一个差异写进第一课证据 2。中文、公开可读；实际调用另需有效凭据。

打开指定章节 →

选读 · ReAct 原始论文 · 约 15 分钟

ReAct: Synergizing Reasoning and Acting in Language Models，Yao 等，ICLR 2023。只读摘要、PDF 第 2 页图 1 与图注，辨认 Thought、Act、Observation。

看前问题：为什么“想出一个答案”与“取得外部观察再调整”不同？看后用情报查询写一个“待核实问题 → 查询 → 观察 → 下一步”的四行示例，填入第一课证据 1。论文说明一种推理与行动交错方法，不规定现代接口字段或授权机制。

英文、公开论文；课内循环图提供中文入口，不要求复现论文实验。

选读 · Anthropic《Building effective agents》 · 约 10 分钟

阅读 What are agents? 与 Agents 两节，用自己的话区分固定工作流和模型参与下一步决策的循环，填入第一课证据 1。英文、公开可读。

02 · 授权检查

选读 · OWASP Authorization Cheat Sheet · 约 5 分钟

阅读 Introduction 和 Validate the Permissions on Every Request。给第二课规则补一句：为什么目标允许仍要核查任务与敏感内容。英文、公开可读；课文有中文解释。

03 · 工具数据流

选读 · OpenAI Function calling · 约 15 分钟

阅读 The tool calling flow 和 Defining functions；选择 Chat Completions 格式对照课内代码。指出提议、程序执行与结果回填分别是谁的职责，并解释 required 的作用，写进第三课证据 2。

英文、公开可读；另一格式 Responses 的字段不同，不直接混用。
