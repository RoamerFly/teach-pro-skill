起点诊断

入门评估

用六道短题了解你对 Agent 开发与安全的认识，帮助课程决定从哪里讲起、讲多细。

使用方法

先凭第一印象独立作答，再展开参考标准；不确定的题选一个最接近的即可。开放题里写「不记得」比猜测更有用。

两点如实说明：参考标准可以随时展开，选择题提交后也会立即显示对错反馈——因此你的作答会被记为可能受提示影响的起点线索，而不是严格的无提示诊断。它仍足以决定第一课从哪里开始。

评估任务

第 1 题 · API 调用的理解

调用兼容 OpenAI 的对话接口（chat completions）时，messages 参数传递的核心结构是什么？

参考标准（建议先作答再展开）

messages 是消息数组，包含角色与对应内容。本题的独立请求由调用方提供相关上下文；不要把这件事等同于服务商的日志留存政策，也不要泛化为所有接口都不支持会话管理。

第 2 题 · 密钥的工程习惯

在一个要调用大模型 API 的 Python 脚本里，API Key 应该怎么存放？

参考标准（建议先作答再展开）

本地练习可通过环境变量传入密钥，代码用 os.environ.get("API_KEY") 读取，避免硬编码在源码里；生产环境可使用密钥管理服务。设置和传递时也要避免明文出现在命令历史、日志或截图中。若使用本地密钥文件，勿将其提交到版本库。

第 3 题 · 工具型 Agent 的工作方式（起点锚）

这门课重点学习能多步决策并调用工具的 Agent。与一次大模型 API 调用相比，它增加了什么机制？这题只用于了解你现在的直觉，课前不必会。

参考标准（建议先作答再展开）

本课程的工具型 Agent 会经历：接收目标 → 模型选择下一步 → 程序执行工具 → 返回观察 → 再决策，直到达到停止条件。第一课将画出这个循环，并标明工具由谁执行。

第 4 题 · 安全概念（起点锚）

安全语境里的提示注入（prompt injection）指的是什么？同样只用来锚定起点，听过或没听过都正常。

参考标准（建议先作答再展开）

直接注入来自直接输入，间接注入藏在待处理外部内容中。没有工具也可能污染回答或泄露已提供的信息；授予工具能力后又增加实际动作的风险，执行层仍须检查授权。

第 5 题 · 动手验证（开放题）

请凭记忆写一小段调用大模型 API 的 Python 代码；记不清代码的话，用文字描述步骤和关键参数也可以。记不住的部分直接写「不记得」——比猜测更有用。

参考标准（建议先作答再展开）

能说明调用流程、构造消息并读取响应，可作为相应能力的线索；只写库名或参数名，仅说明听说过这些词。留空表示本题没有可判断的产出，不影响开课，后续可在课内复核。

第 6 题 · 目标与已有词汇（开放题）

两个小问题：① 你希望这个「AI 安全情报 Agent」最终帮你做什么（比如跟踪哪类情报、输出什么形式）？② 在 Agent 安全方向，你已经听说过哪些词（如提示注入、越狱、OWASP LLM Top 10——都没听过也完全正常，直接说没听过即可）？

参考说明（无标准答案）

这题没有对错。① 用来细化毕业项目的设计；② 用来决定安全内容从多基础讲起。

提示：不要在作答中粘贴真实 API Key、个人隐私或公司内部材料。AI 无法读取浏览器私有存储；从课程启动器打开本页时，作答会自动同步到本地课程目录，下次对话直接生效。
