# Roadmap: 智鉴 Agent

## Mission link

从消息与执行边界走向受控情报项目，开发与安全同时建立。

## Planning assumptions

虚构场景：基本 Python、用过 API、每周五小时、图解优先。实际能力与时程待新作答校准；不按固定课数计算掌握率。

## Phase 1 — 原理与最小实现

展示课：一次 API 调用；信任边界补救；工具数据流推进。后续候选为状态与记忆。阶段门槛：解释请求上下文、正确构造消息并分析越界调用；读取页面不算通过。

## Phase 2 — 安全设计

候选：提示注入、权限、数据边界、异常和预算。产出：边界图与允许/拒绝案例，能说明各约束覆盖与未覆盖什么。

## Phase 3 — 框架与工程

按项目选择具体框架；产出可运行最小系统、日志、测试和恢复设计，核对框架默认行为而非只会调用封装。

## Phase 4 — 安全情报项目

确认获准情报源、输入输出和部署范围；完成富化与报告。门槛包括来源核对、正常/拒绝路径、数据处理与项目反馈。

## Review plan

即时练习之后换情境复查；下次先回忆关键图与权限条件，再依据独立程度与延迟条件更新判断。
