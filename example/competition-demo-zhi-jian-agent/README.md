# 智鉴 Agent · 比赛展示课程

“学途智伴——大学生长期自适应学习智能体”的独立 Demo，由重邮FFBond 制作。基线为 Teach Pro **1.1.0-rc.3**，整理日期为 2026-10-01。

## 打开课程

仅阅读：打开 [index.html](./index.html)。自动保存作答到文件：使用 Python 3.11+，启动本机课程服务。

| 平台 | 启动方式 |
| --- | --- |
| Windows | 双击 start-course.cmd |
| macOS | 双击 start-course.command，或运行 sh start-course.command |
| Linux | 运行 sh start-course.sh |

也可运行 `python serve_course.py`；无图形环境加 `--no-browser`。无需安装第三方 Python 包。静态阅读不需要 Python；服务只监听本机回环地址。

## 展示内容

- 六题可保存的入门评估。
- 三节经校核的完整课：API 与上下文、信任边界补救、工具数据流推进。
- 原创图解、即时检查、开放练习、疑难输入与一手资源导学。
- 教学决策回放与资源中心。
- 统一课程设置：按需选择服务、获取模型、测试连接；未配置也能学习。

课内问答由用户主动确认后发送限定上下文。API Key 默认遮蔽，仅在本地服务进程内存中；不预填凭据，不附带聊天或模型配置。

## 与实测的关系

此副本整理自逐次生成的 TeleAgent Test5 主线与隔离分支，**不是一次生成三课，不是实时生成回放**。课程内容经人工修订；三种选课行为已观察，原生课文仍有失败项。

公开副本没有原始提交、真实画像或预置掌握成绩。合成测试只用于说明“证据不足 → 巩固、具体误区 → 补救、新内容充分 → 推进”。推进分支基于人工修订的前课，不证明完全无人工干预的闭环或长期学习效果。

证据与源文件关系见 [PROVENANCE.md](./PROVENANCE.md)，仓库评测见 [G3 最后分支复核](../../evals/records/2026-10-01-test5-g3-recovery-review.md)。这套课程是展示资产，不把人工编辑结果算作 Skill 新生成行为通过。

## 继续学习

从启动器打开，填写当前课答案和疑难，再在能访问本目录的 Agent 对话中显式调用 teach-pro 请求继续。AI 读取实际新记录；未填写时不能依据预置回放把你判为已掌握。第四课仍是候选，不提前提供正文。

`learner-submissions/`、`learner-chats/`、`.tutor-settings.json` 与缓存由本地运行产生，均被忽略，不属于发布内容。
