学习目标

独立开发一个能搜集安全情报、核对来源、生成报告，并在授权范围内调用工具的 Agent。先通用原理，再具体框架；每周约五小时，按作答与实践结果调整节奏。

  • 理解：画出模型、外部数据、执行层与信任边界。
  • 实现：构造消息、解析调用、回填结果并控制停止。
  • 判断：区分来源真实、动作授权与实际执行。

长期路线

  1. 原理与最小实现：消息、工具循环、状态与记忆；画图并跑通受控模拟。
  2. 安全设计：提示注入、权限、数据边界和异常路径；将约束写进执行层。
  3. 框架与工程：选一个适合项目的框架，补齐日志、测试、预算与恢复。
  4. 情报项目：接入获准数据源，完成情报富化与报告，验证正常与拒绝路径。

下一候选：记忆与状态。实际续课由当前作答决定；真实项目阶段再核实数据源、部署环境与权限范围。
