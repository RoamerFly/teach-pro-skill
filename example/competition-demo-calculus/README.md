# 高等数学零基础课程实测

这是一次通过Codex宿主实际调用Teach Pro的四轮教学对话，模拟学员在浏览器中完成评估、学习和作答，Agent读取保存的原始回答生成课程。

打开index.html查看课程路线、两节正式课和一节关联补充课。实际对话见实际对话记录.md，运行信息见运行来源.json。

第1课讲函数图像上的点与交点。学生在平移函数上提出对称轴疑问后，Agent回应并生成补充课，同时交付从数值表和图像理解极限的第2课。第2课和补充课尚待后续作答。

此副本保留生成时的教学状态和学习记录。原始提交与运行日志留在本地测试目录。路演截图来自实际网页，对话截图为真实对话原文的记录页排版。
