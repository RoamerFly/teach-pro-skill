第 1 课 · 函数图像上的点与交点

看见一个横坐标，就能说出对应的函数值和图上的点；找与 x 轴相交的地方时，能找全所有交点。

课程类型
正式课
预计时间
约 50 分钟，含练习
当前进度

今天要解决什么

入门评估中，你算对了 f(−3)=5，也知道图像与 x 轴相交时 y=0。你从 x²=4 找到了 x=2，还想知道左边是否也有交点，以及横坐标和函数值怎样区分。今天就把这条线连起来：

输入 x → 计算 f(x) → 得到图上的点 (x, f(x))。

学完后，你可以用这条规则读图、找 x 轴和 y 轴交点，并解释为什么一个图像可能与 x 轴相交两次。

一个输入对应图上一个点

把函数想成一台按规则工作的机器。你给它一个允许的输入 x，它按规则算出一个输出 f(x)。在坐标平面里，横坐标写输入，纵坐标写输出，所以这次计算得到的点是 (x, f(x))。函数图像由所有这样的点组成。

输入 x = 1
→
f(1) = 1² − 4 = −3
→
点 (1, −3)

规则是 f(x)=x²−4。这里的 1 是横坐标；−3 是函数值，也是这个点的纵坐标。

用同一个规则，输入 −1 时，先把整个负数放进括号：f(−1)=(−1)²−4=−3，对应的点是 (−1,−3)。两个输入不同，函数值可以相同；图上就有两个高度相同、位置左右不同的点。

说“f(1)=−3”是在报告一次计算的输出；说“(1,−3)”是在指出图上的位置。括号中的第一个数永远读作横坐标，第二个数读作纵坐标。

沿坐标轴读图像

下图画的是 f(x)=x²−4。先在水平的 x 轴上找到输入 1，再沿虚线走到曲线，最后向左读到纵坐标 −3。这就读出了点 (1,−3)。图中的曲线向左右继续延伸，绘图区只显示其中一段。

对这条函数，f(−x)=(−x)²−4=x²−4=f(x)。把输入从 2 换成 −2，输出仍一样，因此图像关于 y 轴对称。这能帮你检查本题是否漏了左侧对应的点。并非每个函数都有这种对称；例如 g(x)=x²+x 时，g(1)=2，g(−1)=0。

与坐标轴相交时，哪个数等于零？

在 x 轴 上，每个点的纵坐标都是 0。所以要找函数图像与 x 轴的交点，就令 f(x)=0，找出所有允许的输入 x，再把每个输入写成点 (x,0)。

你的评估题：f(x)=x²−4。令输出为零：x²−4=0 → x²=4。平方为 4 的实数有两个：2²=4，(−2)²=4，因此 x=2 或 x=−2。逐个写成图上的点：(2,0) 和 (−2,0)。代回函数，两处的函数值都等于 0。

这里有三种不同的说法：x=−2 是一个使函数值为零的输入，也叫一个零点；f(−2)=0 报告它的函数值；(−2,0) 才是与 x 轴相交的点。说“有两个交点”时，需要给两个坐标点。

在 y 轴 上，每个点的横坐标都是 0。所以先算 f(0)=0²−4=−4，交点是 (0,−4)。记法可以对照：

要找什么先令哪个数为零最后写什么
与 x 轴的交点纵坐标 y=f(x)=0所有满足条件的 (x,0)
与 y 轴的交点横坐标 x=0(0,f(0))，前提是 0 可作输入

“令 f(x)=0”之后要把方程的所有实数解找全；有的函数可能有两个、一个或没有 x 轴交点。至于 y 轴交点，只有函数允许输入 0 时才存在。

从计算到图像：一个完整例子

换一个新函数 g(x)=x²−1。我们依次列点、找交点、检查图像位置。

  1. 列几个点。g(−2)=3，g(−1)=0，g(0)=−1，g(1)=0，g(2)=3。相应的点是 (−2,3)、(−1,0)、(0,−1)、(1,0)、(2,3)。每个有序数对的第一项来自输入，第二项来自输出。
  2. 找 x 轴交点。令 g(x)=0：x²−1=0，得到 x²=1，所以 x=−1 或 x=1。交点是 (−1,0)、(1,0)。
  3. 找 y 轴交点。令 x=0：g(0)=−1，交点是 (0,−1)。
  4. 核对图像。平方项使 g(−x)=g(x)，左右两侧同高；列点中 (−2,3) 与 (2,3)、(−1,0) 与 (1,0) 正好成对。曲线从左侧降到 (0,−1)，再向右上升。

以后课堂上出现更复杂的函数，也可以先做同样的三件事：选输入求输出、把结果写成点、用坐标轴条件找交点。

自己试一试

下面是讲解后的即时练习。先在题后写答案，再按需打开提示和解析；这些作答帮助我判断下一课需要怎样衔接。

练习 1 · 读点

从输入写出图上的点

函数 h(x)=x²−9。输入 x=−1 时，函数值是多少？图上对应的点是什么？请指出哪个数是横坐标、哪个数是纵坐标。

查看提示

把 −1 整体代入 x；一个点写成 (输入, 输出)。

查看答案与解析

h(−1)=(−1)²−9=1−9=−8，所以点是 (−1,−8)。−1 是横坐标，−8 是纵坐标，也是函数值。若写成 (−8,−1)，就是把输入与输出的位置交换了；回到 (x,h(x)) 的顺序重写。

练习 2 · 找全交点

写出所有与 x 轴的交点

对同一个函数 h(x)=x²−9，求图像与 x 轴的所有交点。请写出方程的每一个实数解、对应坐标，并用代入检查。

查看提示

x 轴上的纵坐标是 0。x²=9 时，有哪两个数的平方等于 9？

查看答案与解析

x²−9=0 → x²=9 → x=−3 或 x=3，因此交点为 (−3,0) 和 (3,0)。检查：h(−3)=9−9=0，h(3)=9−9=0。若只写一个点，再检查相反数的平方；若只写 x=±3，还要补上坐标点。

练习 3 · 区分两条轴

找到与 y 轴的交点

函数 h(x)=x²−9 与 y 轴的交点是什么？再用一句话解释，为什么这一题要先令 x=0。

查看答案与解析

y 轴上各点的横坐标为 0，所以先算 h(0)=0²−9=−9，交点为 (0,−9)。若得到 (−9,0)，说明把“输出为 −9”写到了横坐标的位置；按 (输入,输出) 检查一次。

练习 4 · 换一个条件

对称轴不在 y 轴时

新函数 k(x)=(x−1)²−4。找出它与 x 轴的所有交点，并计算 k(0)。比较 k(0) 与 k(2)：这幅图像是关于哪条竖直线左右对称？写出你的依据。

查看提示

(x−1)²=4 时，x−1=2 或 −2。输入 0 与 2 到 1 的距离一样。

查看答案与解析

(x−1)²−4=0 → x−1=−2 或 2 → x=−1 或 3，与 x 轴交于 (−1,0)、(3,0)。k(0)=(−1)²−4=−3，所以与 y 轴交于 (0,−3)；k(2)=1²−4=−3。输入 0 与 2 分处 x=1 左右、距离相等，输出相同；把输入写成 1−t 与 1+t，也会得到相同的 t²−4。因此对称轴是 x=1。若沿用上一例的 y 轴对称，检查 k(−1) 与 k(1)：两者分别是 0 与 −4，不相同。

带走这个心智模型

横坐标是输入 x，纵坐标是函数值 f(x)，所以点写成 (x,f(x))。与 x 轴相交时，输出为 0，解 f(x)=0 并找全所有实数解；与 y 轴相交时，输入为 0，算 f(0)。对于 x²−4，两侧同高来自 f(−x)=f(x)，因此 (−2,0) 与 (2,0) 成对出现。
