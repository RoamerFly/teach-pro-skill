学习使命

面向有基本 Python 和模型 API 使用经验的大学生，目标是独立开发安全的 AI 安全情报 Agent。先学通用原理，再学框架；每周约五小时，优先图解理解，再做代码和项目。

路线与阶段

  1. 原理与最小实现：消息、工具循环、调用契约与执行边界。
  2. 状态与安全：上下文、记忆、提示注入、权限与异常处理。
  3. 框架与工程：选用项目框架，补齐日志、测试与预算控制。
  4. 情报项目：接入授权数据源，核对来源，生成可追溯报告。

后续主题为路线候选，由当前课作答决定难度与先后。
