# 渐进师生流程与分句语气验收

日期：2026-10-06。基线：57c0f0c。范围：参赛演示台词、独立录制/配音工具、音视频与说明；Skill 核心及课程运行时未修改。串行完成，无子智能体。

## 因果主线

学习目标 → 调用 Skill → 基础评估 → 图解和代码 → 原资料导学 → 从代码发现疑点 → 首次打开答疑 → 按页面提示连接模型 → 返回同课答疑 → 首问 → 基于回答追问 → 自己总结并作答 → 带记录回宿主续课 → 已有正式/补充课结果回放。

新增“代码引出疑问”和“回到 TeleAgent 读取记录的续课提示词”两镜。设置在学习疑问之后出现；首问延续同一个疑问；追问先复述上轮理解，再区分历史聊天与工具型 Agent；续课结果前先说明回到宿主的操作。十三镜头、22 段口播，教师 15 段，学生 7 段。

## 实录与修正

先合成脚本台词并测量每句时长，再按对应时点真实操作浏览器。实际答疑返回后才合成教师朗读，未预生成或模拟模型答案。全程隔离复制干净 Demo，不读取原学员答案、聊天或配置。

首轮录制发现自动返回行为：从答疑入口进入设置时，返回链接带 `#lesson-tutor`，页面会自动打开原课答疑。原录制脚本尝试再次点击被弹窗遮挡的入口而超时。修正台词为“答疑窗口就回来了”，脚本复用已打开窗口并核验课程路径。此问题属于演示脚本与既有页面行为不一致，并非本轮修复了 Skill 运行时。

首轮在获取模型、连接测试成功后停止，没有聊天请求；两个请求耗时 854 / 1175 ms。故本轮共发送 6 次真实 DeepSeek 请求，定稿录制使用后续完整四次请求，不将失败录制冒充完整验证：

首次未连接入口、携带原课定位的设置跳转、返回同一答疑窗口均核验通过。两轮上下文版本相同，答案完整且与提问配对；作答、疑难和聊天实际保存到隔离目录。系统凭据实际记忆，结束后删除该隔离课程的临时凭据。密钥框始终为 password；浏览器外部请求 0、页面 JS 错误 0。

## 声线与语气

保留已选定的教师 A 声线“阅历姐姐”，采用百炼 `MiniMax/speech-2.8-hd`。按句发送 1.24 / 1.25 / 1.26 / 1.28 / 1.30 原生语速；happy 用于引导、确认与肯定，calm 用于机制解释，其余由模型匹配情感。语气控制不能覆盖已选定的音色或模型，离线测试覆盖该约束。

学生保留 Andre / Qwen3-TTS-Flash，重写七段自然口语，通过疑问、思考、领悟与期待形成变化。该音色不支持独立指令控制，`delivery` 只记录意图，不作为模型参数。没有换成青年大学生音色，也没有声音复刻。

首轮脚本合成 20 段，修正返回台词新增 1 次合成，真实答案新增 2 次合成，本轮共 23 次 TTS 请求。其余片段复用缓存，未对失败 HTTP 请求自动重试。最终字幕复核采用 cached-only，新增请求为 0；公开报告如实记录最后一次离线构建模式。

两角色后期倍率均为 1，源时长等于播放时长，总口播 148.325438 秒。混音只统一响度，不变速、不变调；“哦”“对”等短接话合并到相邻字幕，减少短促闪烁。技术参数来源：[MiniMax API](https://help.aliyun.com/zh/model-studio/minimax-synchronous-speech-synthesis-api)、[Qwen 音色兼容列表](https://help.aliyun.com/zh/model-studio/qwen-tts-voice-list)。
