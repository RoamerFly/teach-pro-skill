# Tutor 回答排版 · 阶段 2

本地固定依赖：Marked 18.0.14、DOMPurify 3.4.16。npm 官方发行包下载后校验 SHA-512，保留原始浏览器脚本与全部许可文件。部署后的课程不访问 CDN，不增加学员安装步骤。

共享渲染模块支持标题、段落、强调、嵌套列表、引用、代码及表格；代码可复制，长表格和代码独立横向滚动。模型 HTML 显示为字面文本，危险链接移除，远端图片只显示描述。原始 Markdown 继续写入聊天文件，用户问题仍用纯文本。

真实 Edge 浏览器合成测试通过：中文与代码井号保持原样、未闭合代码围栏可读、标题降级、表格封装、脚本与 onerror 不执行、javascript 链接不可点击、远端图片不加载。此验证是渲染测试，不是提供商真实模型测试。

Demo 同步共享资产；旧课节正文、评估与学员目录保持不变。大弹窗与设置简化继续在阶段 3 执行。
