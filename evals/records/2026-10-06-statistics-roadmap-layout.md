# 统计学通用性试用的路线布局修复

日期：2026-10-06。基线：2ec3844。来源：用户 TeleAgent 生成的 data-analyst-statistics 课程及错位截图。串行完成，无子智能体。范围为共享路线样式、首页模板与既有统计学页面的局部修复，不扩展教学功能，版本保持 1.1.0-rc.12。

## 原因与责任

用户页面的 phase-card 直接子 span 写成 `class="eyebrow"`，文字包含 `Phase 1 · 当前`、`Phase 2` 等。共享 CSS 对所有直接子 span 设定 1.7rem 固定宽高，默认它只放两位编号；长标签换行后超出盒子，浅底上的白字也难读，部分文字覆盖随后的 H3。

共享 CSS 与该课程副本使用同样的固定尺寸规则，首页模板此前只提供 ROADMAP_HTML 空插槽，没有阶段条目示例。生成结构与样式约定不一致，同时模板缺少明确结构和长文本兼容；不能只归因于学员操作或宿主。结构检查器此前通过，说明静态路径与属性检查不能代替浏览器文本几何检查。

## 局部修复

- 阶段标记改为内容自适应宽高、最小尺寸、自然换行和 max-width，限制阶段条目最小宽度并处理无空格长词。普通 span、eyebrow 与完整 phase-label 都能占据实际文本高度。
- phase-number 保留紧凑数字外观；数字、H3 标题、当前状态和目标段落分别表达。主题配色沿用原变量。
- 首页模板内置 phase-grid，ROADMAP_HTML 只填阶段条目，示例说明数字与状态分开；HTML 输出规范同步该插槽约定，不在 SKILL.md 追加重复规则。
- 统计学首页改用 phase-grid 与 01–05 数字标记，“当前阶段”单独显示；只改 index.html 与 assets/style.css。旧文件先备份到仓库外私有 QA 目录。
- 当前与历史公开 Demo 的共享 CSS 同步，继续维持运行资源逐文件一致性，不改课程正文、保存键、服务逻辑或密钥处理。
