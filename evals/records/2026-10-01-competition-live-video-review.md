# 连续旁白与真实课内答疑视频验收

日期：2026-10-01。队伍：重邮FFBond。作品：学途智伴——大学生长期自适应学习智能体。Skill 保持 1.1.0-rc.3；本轮只更新比赛视频、制作工具与验证记录。

## 本轮调整

讲稿从功能逐项介绍改为学生学习过程：了解基础 → 图解与代码 → 一个具体疑问 → 配置 DeepSeek Flash → 提问、判断与澄清 → 保存学习记录 → 查看课程调整。共 12 个镜头，精确章节时间随视频发布。

旁白采用已有 edge-tts 7.2.8 的 zh-CN-YunxiNeural，整段连续合成，rate -2%、pitch -1Hz。以句子边界对齐镜头，避免逐镜头音频拼接停顿；只向语音服务发送公开讲稿。采用高通与两遍响度归一化，目标 -18 LUFS、真峰值上限 -2 dBTP，不加速语音、不用背景音乐。工具不能听取音频，音色、术语读音与主观流畅度须由用户播放确认，不计为人工听感验收。

## 真实接口与文件验证

录制使用独立课程副本、合成学生问题与作答，运行冻结 Demo 的原生服务与页面。浏览器禁止直接访问外部地址；课程服务向真实 DeepSeek 官方接口请求，未使用模型响应模拟或本地代理改写。

本次成片采用的录制包含以下五次实际提供商操作；HTTP 状态为本地课程接口状态，该服务仅在获得兼容的成功提供商响应后返回 200。

| 操作 | 本地 HTTP | 用时 | 结果 |
| --- | --- | --- | --- |
| 获取模型 | 200 | 337 ms | 返回 deepseek-flash、deepseek-v4-pro |
| 连接测试 | 200 | 1054 ms | 兼容文本连接成功；未发送课文 |
| 首次提问 | 200 | 7575 ms | 回答校园公告疑问并提出判断题，聊天累计 2 条 |
| 判断追问 | 200 | 2230 ms | 指出来源可信不等于执行授权，聊天累计 4 条 |
| 权限澄清 | 200 | 3156 ms | 区分系统提示与运行时独立授权检查，聊天累计 6 条 |

实际配置为 DeepSeek、https://api.deepseek.com、deepseek-flash、max_tokens 4096。三轮回答的课程上下文版本一致，聊天文件包含三条用户消息与三条完整模型回答。课末解释和剩余疑难均从课程服务输出的本地文件读取；保存证据镜头据此展示，不伪造文件。模型回答原样保留，包括前两轮对 system 与程序权限的含混表述；用真实第三轮追问澄清，而不是替换答案。

首轮较早录制成功完成模型获取、连接与两轮答疑。随后重录在 1024 token 配置下，连接测试返回“接口未返回兼容的文本回答”，制作停止，没有继续录制成功状态。参照[DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)，Flash 默认开启思考；低输出上限耗尽是待确认的原因，本次未保存该失败响应的 finish_reason，故不视为已证实诊断。通过已有设置把上限调至 4096 后完成最终录制；最终首问实测 completion_tokens 为 1120。三次录制合计 11 次提供商操作，成片对应最终五次；没有自动请求重试，也没有修改冻结 Runtime。

## 剪辑、隐私与验收边界

- 一条旁白覆盖全片，25 fps 的绝对时间取整避免累计漂移。可剪短超时等待，并在对应章节标注；不加速或改写模型回答。
- 代码镜头的原始录屏发生合成器残影，静态阅读停留段改用本轮同一页面的真实完整截图；图解、切换过程和真实问答保留原始录屏。后续采集脚本在滚动后主动刷新合成器。此修订没有发起额外模型请求。
- 字幕在 810 像素课程画面下方的 90 像素独立区域；标题 19、字幕 28，分句最长 28 字符。字幕随连续旁白时间对齐，不遮盖正文、图解或输入框。
- API Key 通过不回显的标准输入传入，未放入命令参数、脚本或环境变量；设置输入始终断言为 password，不点击小眼睛。保存配置后输入框清空；停止服务后忘记内存密钥。配置、作答与聊天文件检查未包含密钥，变更文本扫描未发现密钥形态值。
- 原始录屏、音轨、课程副本、配置、聊天文件、合成作答及检查帧保留在仓库外 competition-work。公开材料仅含成片、字幕、章节与非敏感请求元数据。原 TeleAgent 学员目录、Skill、公开 Demo 与旧材料保持不变。
- 自适应分支是已有合成测试的回放，已在画面标注；不是实时生成下一课，也不是同一真实学员的长期学习成绩。Tutor 聊天作为续课参考，不作为掌握证明。
