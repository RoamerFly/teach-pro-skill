日期：2026-10-05。用户要求维护者自行模拟大学生学习和填写，不再把测试作答交给用户。

## 条件与隔离

- Skill 为 1.1.0-rc.12；主智能体按 Skill 与相关规范串行工作，无子智能体。
- 使用智鉴 Agent 的校核公开页面作为已有课程，在仓库外新建隔离课程；允许列表只复制 HTML、资产、服务和启动器，不复制实际学员答案、聊天、模型配置、凭据或 Python 环境。
- 画像、作答和疑难均为专家构造的合成场景：[固定夹具](../fixtures/college-learner-lesson2.json)。构造者已知答案；不是独立 learner-model 测试，也不代表真人学习、独立迁移或长期保持。
- 本轮新课由 Codex 主智能体生成；没有启动或操作 TeleAgent，不将结果记成该客户端新协议通过。
- Windows、Edge、本地 Python。服务使用回环临时端口，未配置模型、未请求真实提供商。页面在线推荐的一手资料由维护者另外打开核验。

## 实际闭环

1. 在浏览器打开第二课，选择并提交 C、D、A。前两题反馈正确，第三题反馈错误；保存首次错题，没有把其静默改为全对。
2. 实际填写两轮纸面工具调用过程与两条疑难。示例编号、报告结果和场景均标为合成，不冒充真实 CVE 情报或工具运行。
3. 浏览器自动同步产生第二课 JSON。用新浏览器会话验证从文件恢复；维护者读取其课程、页面、时间和字段，不要求用户导出。
4. 根据“无 Thought 是否免疫注入”与“json.loads 是否够用”的合成问题，本轮交付一节新正式第三课“安全工具调用契约”，并同轮附第二课补充“没有 Thought 仍有注入风险”。正式课只短接旧知，主要教授解析、参数校验、注册、授权和预算；补充用招聘公告的新场景辨析问题，不占正式编号、不阻止主线。
5. 新页面使用原模板与资产，含原创 SVG、完整离线 Python 示例、即时练习、保存入口、一手资料导学；同步首页、全页导航与内部状态，没有生成第四课。
6. 实际操作两页的错误选择、改选和正确反馈，填写合成开放题；生成独立 JSON，并清空浏览器副本后从本地文件恢复。保留第二课首次错误记录。

自动化测试的合成补充作答只是即时交互测试，不能据此将画像更新为真实误区已纠正。第三课示范程序确实执行过，但其中工具与数据仍为离线合成实现。

## 资源核验

第三课优先主读为 [Python 3.13 json.loads 与标准兼容性](https://docs.python.org/3.13/library/json.html#json.loads)，安全映射为 [OWASP LLM01:2025 的格式校验与最小权限策略](https://genai.owasp.org/llmrisk/llm01-prompt-injection/)，选读为 [Toolformer v1 摘要](https://arxiv.org/abs/2302.04761v1)。分别核验相关正文或摘要，不声称论文全文、视频或外部图像核验。精确片段、预算与主动产出已写入课程资源记录和网页。
