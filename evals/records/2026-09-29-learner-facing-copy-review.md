# 学员页面文案：资源取舍不写成解释

## 观察

Test4 第 0001 课的资源区有一段说明为何没有外部视频，提及旧版页面、访问限制和“不为凑数”。这属于制作过程与资源取舍，不帮助学员完成当前阅读任务；同一资源区还以“已核验四项资料”“正文不依赖外链”开场，削弱了导学的直接性。

## 修订

- Test4 课页删除未选视频说明，资源导语改为阅读顺序与用途；原有四项资源、链接和学员输入键保留。
- 未选视频的理由仅在课程内部 `RESOURCES.md` 保留，供后续课程规划使用。
- 通用 Skill 在解释风格与资源策略中区分“面向学员的教学文字”和“内部资源决策”。有选定资源才显示导学区；没有选定资源时省略该区，仍交付完整的正文和练习。实际影响所选资源阅读的访问限制、知识适用条件或安全风险仍需在学员页就近说明。
- 同步调整 `RESOURCE-SELECTION-POLICY.md`、`DAILY-LESSON-FORMAT.md`、`QUALITY-CHECKLIST.md` 与 `templates/lesson.html`，消除原先要求在 HTML 说明未推荐原因的相互矛盾指令。

- Edge/Playwright：390px 下资源区仍有四项，未选视频解释不再出现，页面无横向溢出或 JavaScript 异常。
- `quick_validate.py`：Skill 有效；原有学员评估文件未编辑，尚无第 0001 课提交。
