# rc.10：默认记住与复选框可操作性

日期：2026-10-05。串行执行，不使用真实 Key、不请求真实模型。

## 原因与修正

rc.9 前端在 capability 不可用时禁用并取消记住选项，提交还会静默把记住改为 false；旧配置的 false 也覆盖默认勾选。安装到课程环境后，直接用其他 Python 运行服务仍可能检测不到 keyring。本次未观察到学员原故障页面的运行进程，不认定其具体启动方式；代码条件与隔离复测可确认上述故障路径。

- 设置页每次打开默认勾选，旧会话参数不取消默认值；删除旧密钥后，替换密钥同样默认记住。服务就绪时复选框及其文字标签均可点击；离线静态阅读仍不配置模型。
- 按用户当前勾选提交，不按 capability 静默降级。服务收到未指定记住偏好的配置也默认记住；明确取消后仍可仅用于会话。存储不可用时明确报错，不写成功配置。
- 修正复选框 padding/height；直接运行服务时先复用已安装 `.teach-runtime/`，避免重复安装或依赖检测环境错位。普通启动不下载依赖、不改全局环境。
- 同步模板、公开 Demo 和当前验收课程四个共享文件。保留教学内容及当前配置，不自动使用进程中的真实密钥进行迁移。
