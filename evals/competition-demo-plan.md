# 学途智伴 · 比赛 Demo 制作方案

队伍：重邮FFBond。作品：学途智伴——大学生长期自适应学习智能体。基线：Teach Pro 1.1.0-rc.3；这是制作方案，不是已录好的新视频或最终提交包。

## 展示主线

用“智鉴 Agent：智能体开发与安全实战”讲一个连续故事：有目标但基础有限的学生先评估，读一节完整课，保存答案与疑难，AI 据文件作答选择巩固、补救或推进。图解、资源与可选答疑为这条教学主线服务。

架构按三层说明：

| 层 | 职责 | 关键输出 |
| --- | --- | --- |
| Skill 教学协议 | 评估、证据判断、疑难处理、逐课决策与内容校核 | 当前一课、画像、路线、学习记录 |
| 本地课程工作区 | 提供学习页面，保存作答与疑难供续课读取 | HTML、learner-submissions、状态文件 |
| 可选 Tutor | 课程设置中的模型选择，结合当前课答疑 | 按课保存的聊天，作为续课参考而非能力证明 |

核心创新讲“逐课决策 + 文件连续性 + 证据条件”，不把界面功能罗列当创新，也不把外部教学模型和可选 Tutor 混为同一个配置入口。

## 素材整理

1. 新建独立展示目录，不移动或覆盖 Test5 原始评估、分支答案与快照。已有 example 和旧最终包均先保留。
2. 从经校核的首页、评估、第一课与补救课整理高质量 Demo；保留图解、资源导学、练习、疑难和动态候选。资源逐项核验，运行时资产匹配 rc.3。
3. 用合成演示作答；展示页旁标“演示数据”，资料中注明“课程内容经人工校核”。真实评估和私人画像不复制进公开 Demo。
4. 动态选课使用三分支原生学习记录作为证据；手工修订课文用于内容展示，二者区别说明。现有样例不是实时新生成，录屏标明“实测结果回放”。
5. AI 设置采用 DeepSeek：展示服务类型预设地址、获取模型、下拉选择、默认遮蔽 Key、连接测试、返回课程。获取/测试只有真实成功才录成功画面，未运行结果不补造；不在成片或提交文件中显示密钥。

## 175 秒成片分镜

| 时间 | 画面 | 要传达的信息 |
| --- | --- | --- |
| 0–15 秒 | 作品标题 → 课程首页 | 长期学习需要持续了解基础与调整课程 |
| 15–40 秒 | 入门评估输入 → 路线 → 第一课图解 | 先评估，一次只交付一课；图解解释当前目标 |
| 40–65 秒 | 练习与疑难框 → 本地演示 JSON | 作答自动保存，续课 AI 能读文件，学生不搬运记录 |
| 65–105 秒 | 具体误区 → 原生决策记录 → 补救课 | 不机械跳课，先答疑并针对错误推理教学 |
| 105–125 秒 | 三分支结果对照 → 推进课数据流图 | 相同课程因输入不同而选择巩固、补救、推进；合成场景观察 |
| 125–155 秒 | 课程设置 DeepSeek 操作 → 当前课答疑 | 可选配置，不影响基本阅读和保存；成功画面须有实际请求证据 |
| 155–175 秒 | 架构三层与验证摘要 | 文件持续性、逐课自适应、内容校核；真实长期成效尚待验证 |

字幕用底部一至两行紧凑底条，避开图解与输入；旁白分句录制，模型名称与术语单独检查读音。先锁镜头和时长，再录音和合成，最后逐帧检查密钥遮蔽、字幕遮挡、画音对应与总时长。
