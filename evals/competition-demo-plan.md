制作状态：独立 Demo 八页已完成内容校核与 Windows 浏览器验收，见 [展示入口](../example/competition-demo-zhi-jian-agent/README.md) 和 [验收记录](./records/2026-10-01-competition-demo-review.md)。[新版参赛材料](../example/competition-materials/README.md)包含六页 Word 和约 171 秒视频；视频已补录真实 DeepSeek Flash 模型获取、连接测试与三轮问答，采用连续旁白。Word 的截图与材料状态待定稿同步，最终提交包未制作。

## 展示主线

用“智鉴 Agent：智能体开发与安全实战”讲一个连续故事：有目标但基础有限的学生先评估，读一节完整课，保存答案与疑难，AI 据文件作答选择巩固、补救或推进。图解、资源与可选答疑为这条教学主线服务。

架构按三层说明：

| 层 | 职责 | 关键输出 |
| --- | --- | --- |
| Skill 教学协议 | 评估、证据判断、疑难处理、逐课决策与内容校核 | 当前一课、画像、路线、学习记录 |
| 本地课程工作区 | 提供学习页面，保存作答与疑难供续课读取 | HTML、learner-submissions、状态文件 |
| 可选 Tutor | 课程设置中的模型选择，结合当前课答疑 | 按课保存的聊天，作为续课参考而非能力证明 |

核心创新讲“逐课决策 + 文件连续性 + 证据条件”，不把界面功能罗列当创新，也不把外部教学模型和可选 Tutor 混为同一个配置入口。

## 素材整理

1. 新建独立展示目录，不移动或覆盖 Test5 原始评估、分支答案与快照。已有 example 和旧最终包均先保留。
2. 从经校核的首页、评估、第一课与补救课整理高质量 Demo；保留图解、资源导学、练习、疑难和动态候选。资源逐项核验，运行时资产匹配 rc.3。
3. 用合成演示作答；展示页旁标“演示数据”，资料中注明“课程内容经人工校核”。真实评估和私人画像不复制进公开 Demo。
4. 动态选课使用三分支原生学习记录作为证据；手工修订课文用于内容展示，二者区别说明。现有样例不是实时新生成，录屏标明“实测结果回放”。
5. AI 设置采用 DeepSeek：展示服务类型预设地址、获取模型、下拉选择、默认遮蔽 Key、连接测试、返回课程。获取/测试只有真实成功才录成功画面，未运行结果不补造；不在成片或提交文件中显示密钥。

## 当前成片分镜

| 时间 | 画面 | 要传达的信息 |
| --- | --- | --- |
| 0–26 秒 | 课程首页 → 入门评估 | 先了解学生基础、目标与学习时间 |
| 26–56 秒 | 调用图解 → 最小代码 → 信任边界疑问 | 从理解一课走到需要讨论的具体问题 |
| 56–81 秒 | DeepSeek 设置 → 获取模型 → 保存 → 测试 | 实际选择 deepseek-flash，密钥遮蔽，输出上限 4096 |
| 81–125 秒 | 本课发送范围 → 首问 → 判断追问 → 权限澄清 | 三轮真实模型交流，并核对含混解释 |
| 125–158 秒 | 作答与疑难 → 实际保存文件 → 课程调整回放 | 聊天落盘；已有合成测试展示逐课决策 |
| 158–171 秒 | 架构与作品总结 | 教学协议、本地记录与可选答疑的分工 |

字幕使用课程画面外的紧凑底条，避开图解与输入；旁白一次连续合成，再按句子边界安排镜头，音频不加速。成片完整解码并抽取所有章节代表帧，复核密钥遮蔽、字幕位置、正文与总时长；用户播放确认音色、流畅度与术语读音。精确章节时间以视频的 video-chapters.json 为准。
