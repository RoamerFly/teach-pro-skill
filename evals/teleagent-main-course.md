# 智鉴 Agent · TeleAgent 主线复测

目标是完善参赛 Skill“学途智伴——大学生长期自适应学习智能体”。固定课程主题用于比较版本，不把教学指令绑定到 Agent 开发，不以一门课验证结果宣称多学科或长期学习效果。

## 固定学习条件

- 基础：会基本 Python、调用大模型 API，未做过 Agent 项目。以上是自述，不是已验证能力。
- 目标：独立开发安全的 AI 安全情报 Agent。
- 顺序：先通用原理，再具体框架；开发与安全结合讲解。
- 时间：每周约五小时，无明确截止日期。
- 偏好：从零逐步讲解；图解与理解优先，推导和代码实战其次，项目第三。

## 产物与测试隔离

仓库中的 `example/ai-agent-security-intelligence/` 用于展示和参考，不把它的 HTML、人工诊断或历史草稿复制给新建课测试作为答案。已有示例的自述与确认能力混写等问题仍须复核，不能视为标准答案。

建议新生成产物写入 `E:\A_Myskill\teach-pro\TeleAgentTest4`，保留同一课程名称与目标。此目录是建议位置，未自动创建或运行 TeleAgent。若实际使用其他目录，记录真实位置即可。不要覆盖原课程、原始作答或旧测试。

每轮记录 TeleAgent 版本、实际模型、导入包版本或指纹、提示词、产物路径及结果。顺序执行，不开并行子智能体。测试用回答和聊天标为合成；真实学习数据单独保留。

## 串行步骤

| 步骤 | 操作 | 验收重点 |
| --- | --- | --- |
| T01 起点评估 | 导入当前 Skill，以固定学习条件请求先评估 | 画像不编造掌握；评估有可保存输入；首页有默认课程设置；按要求不提前开课 |
| T02 第一课 | 在浏览器提交评估，记录实际答案及提示条件，再请求第一课 | 只生成一课；读取本课程记录；图文、资源、练习与解释相符；保存恢复正常；无需 AI 配置也能学习 |
| T03 动态续课 | 从同一课后状态分别测试证据不足、具体误区、补救后新证据 | 教学选择真正因证据改变；疑难先被处理；不虚构通过，不把自检题选对当长期掌握 |

T03 的三个分支串行使用独立课程副本，避免一个分支的状态污染另一个。证据不足分支只说“看完了，继续”；具体误区分支可使用已有 `fixtures/0001-misconception.json`，须适配新课实际字段与问题，不强行沿用旧 HTML 的题目编号。补救分支在实际补救课生成后提供新的情境作答，并记录是否见过解析；不提前为尚未生成的题目伪造完成记录。

核心教学闭环成立后再测可选 AI 答疑：默认设置、主动配置、上下文确认、聊天保存与续课引用。真实模型连接另记结果，需由用户选择服务并同意请求；演示不显示 Key，不把模型回答当作学员掌握证据。
