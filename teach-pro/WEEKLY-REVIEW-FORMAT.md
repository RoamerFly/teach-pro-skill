# Weekly or Phase Review Format

```md
# Review: {日期范围或阶段}

## Mission progress
- 当前使命：
- 本周期实际推进：

## Verified capabilities
- {能力 + 证据层级}

## Exposure only
- {接触过但尚未验证的内容}

## Recurring misconceptions
- {误区 + 出现情境}

## Retention check
- 已能延迟回忆：
- 需要间隔复习：

## Roadmap changes
- 保留：
- 调整：
- 推迟或删除：

## Next phase gate
- {下一阶段前需要展示的能力}

## Next actions
1. {下一课}
2. {复习任务}
3. {真实实践或作品}
```

## 规则

- 复盘围绕证据，不用“完成了几课”代替能力评估。
- 把接触过与掌握严格分开。
- 路线调整要说明原因。
