# Resource Selection Policy

## 原则

资源必须服务于当天一个明确学习目标。课程本身负责讲懂，外部资料只承担补充视角、原始证据、演示或额外练习。

## 分层导学与学习负担

- 普通概念课通常 1–3 项不同用途的精选资源；确有互补价值时可扩展到 2–4 项或更多，不设机械上限。补救课、纯练习课可更少。
- 优先学习项通常 1–2 项，其他标为选读、默认折叠。不要把所有推荐都变成必做任务。
- 根据目标考虑原理主读、视频精学、安全/实践映射、选读进阶；不机械凑齐四类，但应检查关键视角是否缺失。跨领域课不能只推荐其中一侧。
- 时间预算包括指定片段阅读/观看和主动产出，不用整套课程时长冒充本课负担。说明先后顺序和本周优先项。
- 没有可靠且匹配的资料时说明具体缺口；不因模板写“可为空”而跳过检索，不因凑数推荐差资源。
- 自制视频属于核心讲解材料，不计作外部一手资源；是否推荐外部视频由其独特教学价值决定。

## 文档链接的精度

优先顺序：

1. 具体章节锚点。
2. 单篇文章或单个标准条款。
3. 特定版本的 API/技术页面。
4. 合法可访问的教材具体章节说明。

不得只给官网首页、文档总站、搜索页或宽泛合集。

## 视频链接的精度

- 必须是具体视频，不是 UP 主主页或频道首页。
- 多分 P 视频要说明具体 `P`，尽可能链接到该分 P。
- 长视频在能实际核验时标明建议观看区间，例如 `08:20–17:40`；不能核验则给页面已确认的主题范围和自主观看预算，并明示未核验精确时间段，不编造定位。
- 推荐说明必须写清该段对应本课哪个知识点。
- 中文内容合适时优先中文；B 站优先使用具体 BV 视频链接。

## 核验字段

每条资源在内部记录中包含：

- 标题
- 发布者或机构
- URL
- 类型
- 语言
- 对应知识点
- 推荐章节、分 P 或时间段
- 预计时长
- 适用版本或日期
- 最后核验日期
- 选择原因
- 导学角色、优先级与阶段/当前课
- 看前问题、阅读/暂停观察任务、看后产出（适用时）
- 可访问性：语言、字幕、登录/付费、网络限制与替代路径
- 核验程度：正文/目录/公开简介/播放验证；明确未核验部分

公开简介可以支持“主题适合”的候选推荐，不能支持具体演示细节、时长或时间戳。受登录限制的视频只作为注明限制的选看项，并提供已核验文字或本课练习替代；不能标为已完整核验。估计的学习预算要与视频实际片长区分。

## 逐课执行与长期中心

1. 读取当前目标、学员偏好/约束和上一课疑难，先查资源库，再补检索。
2. 选出各自承担明确职责的材料；内容重复时只留更适合的一项。
3. 核验并写入 `RESOURCES.md`；将具体导学任务呈现到本课“本课一手阅读与视频”。
4. 跨课复用或资源较多时维护 `reference/resource-learning-center.html`：当前优先项、阶段候选、学习任务、访问限制、最后核验与替代路径。从首页和课程导航可达。
5. 生成下一课时依据提交的资源学习产出与疑难调整；资源中心只作规划，不自动解锁课程、不以观看标记更新掌握。

候选资源不需要在新建课程时一次搜齐；缺口注明并在对应阶段进入前核验，不生成占位链接。

## 质量判断

优先：

- 官方文档、标准和原始资料
- 公认教材或专家
- 有明确教学结构、示例可靠、维护良好的中文内容
- 与用户版本、目标和基础匹配的资料

谨慎或排除：

- 标题党、营销软文、搬运内容
- 没有来源且结论绝对化的教程
- 已明显过时但未说明版本的内容
- 需要大量未学前置知识的资料
- 链接失效或无法核验的页面

## 写入 HTML 的资源卡格式

每个资源卡必须回答：

1. 这是什么？
2. 为什么现在看？
3. 具体看哪里？
4. 需要多久？
5. 看完应能做什么？
6. 优先学还是选读？访问受限时怎么办？

视频精学任务包含：观看前先预测一个机制；观看中至少一次暂停画图/预测/复写；观看后闭卷解释或迁移到自己的任务。阅读任务也应有具体产出，而非“了解更多”。产出可直接填入本课已有学习记录输入框；不另设必填表单或要求手动导出。

示例：

```text
视频：某课程第 6 集《……》
观看：P6，05:10–14:30
用途：观察本课讲解的三个步骤如何在真实案例中出现
预计：10 分钟
完成标准：能暂停视频并指出每一步对应的判断依据
```

## 禁止行为

- 不得伪造 URL、标题、分 P、时间戳或版本。
- 不得只根据搜索摘要就断言资源内容。
- 不得把资源列表当成课程主体。
- 不得用“推荐一个完整系列自行学习”代替当天教学。
