正在连接本地课程服务…

除“自定义”外，切换类型会自动填充默认 API 地址与连接模式，地址仍可编辑；“自定义”保留当前地址供手动修改。填写 Key 后点击“获取模型”，从实时列表中选择；不支持列表的服务可手动输入模型 ID。获取列表不计入答疑，也不发送课程正文。

支持兼容 Chat Completions 的文本、非流式接口，不保证所有提供商兼容。可填基础地址或完整 /chat/completions 路径。本机模式只允许 localhost、127.0.0.1 或 ::1，不支持局域网。

数据与隐私

  • API Key 只在本次本地服务内存中；保存后输入框清空。服务重启后需要重新输入。
  • 提供商、地址、模型等非密钥配置保存到当前课程的 .tutor-settings.json，不会写入其他课程。
  • 每课聊天自动保存到 learner-chats/；本页不发送课程正文、不读取聊天记录。模型配置不会合并各课聊天。
  • 云端答疑会将已确认的数据发送给所选提供商；本地保存不等于本地推理。请勿在问题或答案中输入密钥、隐私或未授权材料。
  • 答疑 AI 不执行工具、不改课程，也不自动生成下一课。静态阅读无需配置 AI。
