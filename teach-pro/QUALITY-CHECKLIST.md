# Quality Checklist

## 教学完整性

- [ ] 本课只有一个紧密核心目标，直接服务 Mission，并形成一个明确的小胜利；必要前置已补齐。
- [ ] 解释包含直觉、正式表达、机制、示例和边界。
- [ ] 没有用“显然”“其余类似”跳步。
- [ ] 代码、公式、动作或图表都有解释。
- [ ] 理解检查能揭示心智模型，而非只测表面记忆。
- [ ] 没有把刚讲完后的流畅表现直接当成长期掌握；需要时安排延迟提取、变式或迁移。
- [ ] 若目标涉及现实判断或高情境技能，已说明哪些部分需要真实项目、教师/同行/社区或环境反馈来形成 wisdom。
- [ ] 错误反馈指出原因，并提供新的补救检查。
- [ ] 选择题各选项在可见长度、句式和信息密度上等价；自然可行时词数一致、字符数接近，没有通过格式泄露答案。
- [ ] 每课结尾明确提醒学习者可以继续向教师追问、要求换一种解释或索要更多例子。
- [ ] 只生成当前一课；下一课的主题与难度依据已提交的答案、疑难和掌握证据决定。

## HTML 交付

- [ ] 用户教程为 `.html`。
- [ ] `index.html` 能进入当前课程。
- [ ] 页面标题、语言、视口和字符集正确。
- [ ] 左侧导航、页内目录、上下课导航可用。
- [ ] 手机端不重叠、不溢出。
- [ ] 图片有 alt，按钮可键盘操作。
- [ ] 需要图解的关系或流程有清晰、原创、带图注的视觉表示；正文说明了如何读图，手机端仍可看清。
- [ ] 若加入视频，播放器可直接播放，有可用字幕、海报和文字替代；无自动播放，视频不遮挡正文或交互。
- [ ] 代码可复制，答案默认折叠。
- [ ] 折叠卡片展开后，文字稿、答案、选读及列表均保留左右内边距；段落 margin 简写不使正文贴边，手机端无溢出。
- [ ] 入门评估可逐题输入，课程末尾可输入答案和疑难；本地恢复、清空、导出可用。
- [ ] 学习者入门评估位于 `practice/entry-assessment.html`，与 `ENTRY-ASSESSMENT.md` 分开；根目录无误放的同名 HTML。
- [ ] 本地服务模式能自动写入当前课程 `learner-submissions/`，AI 下次对话能直接读取；页面准确区分同步成功和仅浏览器保存。
- [ ] 同步不可用时保留浏览器恢复与备份下载，且不假称 AI 已看到答案。
- [ ] 深浅色和打印样式可用。
- [ ] 没有未替换占位符、TODO 或断尾。
- [ ] 超长文件若采用多次写入，最终仍保持为同一个逻辑文件，且续写边界无重复、遗漏、断标签或编号错乱。

## 路径与文件

- [ ] 本地 CSS、JS、图片、视频、字幕和海报路径存在，直接打开 HTML 与本地服务模式均可使用。
- [ ] 已先复用 `assets/` 中现有组件；可跨课程页复用的新 CSS/JS/组件没有被重复内联。
- [ ] 所有内部链接均留在当前课程工作区。
- [ ] 本地服务只监听回环地址，限制静态文件和提交 API；学员原始答案被版本控制忽略。
- [ ] 课程根目录有合并后的 `.gitignore`，排除 `learner-submissions/`、`learner-chats/`、`.tutor-settings.json` 与 Python 缓存；未覆盖用户已有规则。
- [ ] Windows、Linux、macOS 启动器均位于课程根目录；静态模式提示不指向某一系统专用文件；无图形环境能用 `--no-browser` 获取本机 URL。
- [ ] 新课程已加入首页并使用正确序号。
- [ ] 上一课、下一课和首页链接正确。
- [ ] 未生成的候选课程没有可点击的课程链接。

## 资源

- [ ] 已评估原理主读、视频精学、安全/实践映射与进阶是否需要；资源角色互补，不因追求少链接遗漏关键视角，不机械凑数。
- [ ] 优先/选读标识清楚，阅读观看与主动产出纳入时间预算；选读默认折叠。
- [ ] 资源有具体学习任务和产出；视频有看前预测、暂停观察与看后迁移，复用已有学习记录输入框。
- [ ] 文档指向具体章节或单篇内容。
- [ ] 视频指向具体单集/分 P，并在需要时标明时间段。
- [ ] URL、标题、版本与定位按实际能力核验；公开简介不冒充完整内容核验，未验证的时间戳/时长没有被编造。
- [ ] 登录/付费/语言/网络限制及替代路径已说明；自制讲解视频不冒充外部一手资源。
- [ ] 长期资源中心在适用时可从首页/课程进入，未来阶段明确为候选；没有提前生成下一课或把观看记为掌握。
- [ ] 没有主页、搜索页、无定位合集或编造链接。
- [ ] 即使不打开资源，课程主体仍然完整可懂。
- [ ] 外部图片或视频若被提取和打包，已确认来源、许可和署名；许可不明时改为原创图解。

## 可选课内答疑（仅启用时）

- [ ] 全部页面左侧置顶“课程设置”；模型列表获取与下拉选择、配置、连接测试与忘记 Key 仅在 settings.html，课程页无配置表单；Key 默认遮蔽、主动点小眼睛才显示且保存后清空，移动导航与返回学习入口可用。
- [ ] kind 下拉框预设地址/模式/参数一致；自定义不覆盖地址，切换清空未提交 Key 且不发请求；刷新恢复 kind，旧配置保持原地址并归为 custom。
- [ ] OpenAI kind 使用 developer 教学消息，其他兼容 kind 保留 system；连接测试不发送课文。
- [ ] 配置全课程共用且聊天按课隔离；跨标签页配置变化后，课程页重新获取发送确认，不沿用旧状态继续请求。
- [ ] 已读取 LOCAL-TUTOR-SPEC；页面确认真实发送范围，协议限制与静态降级明确。
- [ ] Key 仅留服务会话，不进入浏览器存储、课程文件、日志或提交包；非密钥配置与聊天均排除发布。
- [ ] 当前课上下文可预览，折叠答案/输入/其他课程未自动发送；回答安全渲染，无工具执行能力。
- [ ] 聊天成功、失败、中断状态真实，刷新恢复、课节隔离、忘记 Key 与确认删除验证通过。
- [ ] 随机会话凭证、同源限制、网络目标检查、重定向拒绝、预算/超时/并发已测试。
- [ ] 生成下一课时读取当前课聊天，区分学员证据与 AI 示例，不虚构掌握。

## 状态

- [ ] 学习记录只写入有证据的能力。
- [ ] 没有把“看过”“继续”误记为掌握。
- [ ] 路线图、首页进度和课程标记一致。
- [ ] 尚存误区或缺口已被准确记录。
- [ ] `NOTES.md` 中的稳定教学偏好已在本课实际体现，而不是只被记录。
