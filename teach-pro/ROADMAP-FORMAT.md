# ROADMAP.md Format

```md
# Roadmap: {课程名称}

## Mission link
{一句话说明路线如何服务 MISSION.md。}

## Planning assumptions
- 当前起点：
- 可用时间：
- 预计周期：
- 截止日期：
- 主要教学模式：

## Phase 1 — {阶段名}
### Outcome
{阶段结束时能完成什么。}

### Core capabilities
- [ ] {能力}
- [ ] {能力}

### Suggested lessons
1. {课程主题}
2. {课程主题}

### Gate to advance
- {必须展示的理解或表现证据}

### Review plan
- {需要间隔复习的内容}

## Phase 2 — {阶段名}
{同上}

## Milestones
| 里程碑 | 目标日期 | 可观察交付物/表现 | 状态 |
|---|---|---|---|
|  |  |  | 未开始/进行中/已验证 |

## Current position
- 当前阶段：
- 最近完成：
- 尚存缺口：
- 下一最小目标：

## Revision log
- {日期}：{为何调整路线}
```

## 规则

- 路线图是动态依赖图，不是必须严格执行的日历。
- 阶段门槛必须可观察，不能只写“学完章节”。
- 不按任意固定一年或固定课数生成；周期来自目标与时间约束。
- 新证据出现后可以调整，但要记录原因。
