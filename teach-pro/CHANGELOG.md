# Teach Pro 版本记录

公开版本从 1.0.0 开始编号。此前开发阶段的迭代统一归入首发能力，不作为本仓库的公开版本历史。当前行为以 `SKILL.md` 和专项规范为准。

## 1.1.0-rc.12 · 正式课与补充课 — 2026-10-05

- 2026-10-09 完整示例增强：增加校园消费统计的共同起点与 A/B 合成作答分支，展示图解教学、证据边界、不同支架的新正式课与独立补充页；可离线构建并真实体验保存。保留最小示例与共享 Runtime，不把预写案例标为宿主新生成结果。

- 2026-10-09 发布规范收尾：描述明确系统学习、备考、技能提升与续课请求；兼容 metadata 提供中文名称与简介；增加按需文档入口和可复现统计学最小示例。不改变教学规则、显式调用策略或课程运行时。

- 续课时交付一节正式课，按需同轮配套一节独立补充课；旧课点评、补救和诊断不再替代新目标教学。
- 补充页关联正式课但使用独立保存 ID、答案与聊天，不占正式课序号与进度；首页分区、导航层级及标题分类纳入模板规范。
- 标题栏兼容正式、补充与旧课；已有课文、文件名和学员数据不自动迁移。更新规则与运行展示不等于 TeleAgent 原生生成已通过，需复测新交付方式。
- 资源导学补丁：主指令和模板明确主动评估外部视频，区分视频推荐与正文播放器；比赛 Demo 补充逐课视频任务及核验记录，不增加必看数量或新交互。
- 2026-10-06 路线布局修复：阶段标签不再固定宽高，长文字自然换行；首页模板明确数字、标题与状态的结构，兼容旧 span / eyebrow，避免标签溢出覆盖标题。
- 2026-10-06 首页主题修复：Hero 渐变、纹理、标题、标签与进度区跟随明暗模式，保留各视觉方向；长标题和进度说明可自然换行，打印隐藏装饰纹理。

## 1.1.0-rc.11 · 自适应启动 — 2026-10-05

- 将手动安装依赖改为三端统一自适应启动：缺少 keyring 时自动准备课程隔离环境、核验并继续启动；就绪时直接复用，安装失败不阻塞课程阅读。
- 安装进程与核验均限时，不改全局 Python；保留离线会话启动与旧维护参数。移除正常流程中要求手动安装再重启的提示。
- Skill 规范、模板脚本、公开 Demo、现有验收课程与首次启动实测同步；不改变教学内容，Word/视频未重制。

## 1.1.0-rc.10 · 默认记住设备修复 — 2026-10-05

- 设置页默认勾选记住此设备，旧会话状态不取消默认值；服务可用时选项可点击。保存不再按能力检测悄悄切换为会话模式，存储不可用明确报错，用户仍可主动取消勾选。
- 直接使用系统 Python 运行服务时，自动复用已安装的课程隔离环境，避免装有 keyring 却检测不到；不自动安装依赖。修正复选框尺寸与点击样式。
- 模板、公开 Demo、现有验收课程和回归同步，教学内容及比赛文档/视频不变。

## 1.1.0-rc.9 · 设备凭据恢复 — 2026-10-04

## 1.0.0 · 首次公开发布 — 2026-09-28

- 面向任意知识与技能，以 Mission、学员画像、入门评估和动态 Roadmap 组织长期学习。
- 一次只生成一节 HTML 课程，依据学员答案、疑难与可验证表现选择推进、补救或深化。
- 区分知识、技能与现实判断，以及即时流畅表现和长期保持；支持主动回忆、复习与迁移。
- 提供紧凑响应式页面、导航、深浅色、折叠答案、代码复制、打印及图解/视频接入规范。
- 精选资源按具体目标导学，提供定位、任务、时间预算、访问限制与核验记录。
- 入门评估位于 `practice/entry-assessment.html`；作答支持浏览器副本、本地文件自动同步与备份导出。
- 提供 Windows、Linux、macOS 启动器；本地服务不可用时仍可静态阅读。
- 可选课内 AI 答疑按课保存聊天，统一在课程设置页配置服务、获取模型列表并选择模型；列表不可用时支持手动 ID。
- API Key 默认遮蔽、仅保留在服务会话内存；限定发送上下文，区分接口请求、认证和额度等错误。
- 提供课程隐私忽略模板、质量检查与可复用资产；不把 AI 示例、阅读或观看记录直接判为掌握。
