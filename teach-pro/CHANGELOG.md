# Teach Pro 版本记录

公开版本从 1.0.0 开始编号。此前开发阶段的迭代统一归入首发能力，不作为本仓库的公开版本历史。当前行为以 `SKILL.md` 和专项规范为准。

## 1.1.0-rc.16 · 对话分支与图文答疑 — 2026-10-26

- 问题与回答支持复制；修改问题保留原版本，重新生成保留回答版本，左右切换恢复对应的后续对话。schema 2 保存消息父链与当前路径，旧聊天原位兼容，后续请求只使用当前分支。
- 生成中可停止上游请求，保留已接收的正文、思考和未发送草稿；思考与正文分别流式展示、Markdown 排版和本地保存。
- 输入区可选择本次模型与思考程度；模型能力随列表保存，使用提供商对应参数，课程默认连接保持统一设置。
- 支持上传、粘贴、拖入图片与上传文本／代码附件，提供缩略图、文件名和移除操作；附件与对话分支关联保存并随历史重放。

## 1.1.0-rc.15 · 整门教材上下文与选文定位 — 2026-10-26

- 课程编号采用普通数字，区分代码讲解点与实际行号；同步修订 Demo 注释、正文引用和图解，更新参赛 Word 与演示中的上下文设置、题后作答镜头。
- 修复折叠参考答案和补充解释不进入答疑上下文的问题；默认带入同课程全部已生成网页教材，不截取前24000字，明确标记当前提问页、课号、标题和正式／补充类型。
- 统一设置页新增“上下文设置”：整门课程／仅当前课、参考答案、资源导学，以及最近5轮／10轮／本课全部已完成对话。旧配置自动使用默认值，修改保存后生效；长回答不再被旧历史字符预算排除。
- 选文自动附带服务端确认的章节、参考标准标签和所在段落，重复短语按选中位置匹配。跨课答疑保留教材来源清单，聊天仍按课保存，方便续课 AI 查阅。

## 1.1.0-rc.14 · 长回答完整显示与继续答疑 — 2026-10-23

- 持续接收模型正文，取消本地正文字数、SSE 累计与单事件体积、JSON 回答体积、浏览器传输总量和固定总时长截断；仅在连接持续无数据时超时。
- 长回答原文完整保存，刷新可恢复，不再因单条正文或聊天文件超过旧长度门槛而拒读。正常回答无状态提示；实际中断只在回答末尾简短提示，不重复占用问题区与输入区。
- 输出 token 预算默认自动，留空时交给提供商；可在高级设置填写正整数，保留已有手动预算与模型专用参数。连接测试仍使用小预算。
- 最近一条中断回答支持手动“继续回答”，带上原问题、选文和已收到的全部正文；保留草稿，不自动续费请求。原始状态继续供课程生成 AI 参考。

## 1.1.0-rc.13 · 答疑响应分层限额修复 — 2026-10-23

- 修复把SSE完整传输量当成正文大小、正常回答仅数千字也误触512 KiB上限的问题。累计流16 MiB、单事件1 MiB、JSON回答回退4 MiB；模型列表仍512 KiB，正文仍24000 Unicode码点。
- 本地正文截断不再误报断流；未知完成状态不标complete。真实传输/事件超限保留已接收安全正文与有限字节/事件计数，原始思考和上游错误不入日志；保持密钥跨片段隐藏与无自动重试。
- 前端按Unicode码点计数以免表情/扩展汉字误触限额；NDJSON安全预算覆盖首尾历史快照。响应循环期限180秒，单次阻塞30秒不变。
- 增加可对技能模板和课程部署副本执行的离线响应回归；隔离回环浏览器验证长流、Unicode、JSON回退与不完整恢复。升级保留学员记录和配置，重启服务/刷新网页生效；不把本地模拟冒充真实提供商测试。

## 1.1.0-rc.12 · 正式课与补充课 — 2026-10-05

- 2026-10-17 题后原位作答：每道开放练习在题干后提供独立自动保存框，选择题仍原位选择；课末只保留疑难记录。模板、练习规范和示例同步，旧页面迁移保留字段 ID 与保存键。

- 2026-10-10 用途与价值整理：明确长期学习中的进度整理、上下文接续与下一步安排，说明本地课程状态、作答证据续课和正式／补充分流如何降低学习组织负担。日常版与赛事版从同一源码发布，教学协议、模板与运行组件不变。

- 2026-10-09 完整示例增强：增加校园消费统计的共同起点与 A/B 合成作答分支，展示图解教学、证据边界、不同支架的新正式课与独立补充页；可离线构建并真实体验保存。保留最小示例与共享 Runtime，不把预写案例标为宿主新生成结果。

- 2026-10-09 发布规范收尾：描述明确系统学习、备考、技能提升与续课请求；兼容 metadata 提供中文名称与简介；增加按需文档入口和可复现统计学最小示例。不改变教学规则、显式调用策略或课程运行时。

- 续课时交付一节正式课，按需同轮配套一节独立补充课；旧课点评、补救和诊断不再替代新目标教学。
- 补充页关联正式课但使用独立保存 ID、答案与聊天，不占正式课序号与进度；首页分区、导航层级及标题分类纳入模板规范。
- 标题栏兼容正式、补充与旧课；已有课文、文件名和学员数据不自动迁移。更新规则与运行展示不等于 TeleAgent 原生生成已通过，需复测新交付方式。
- 资源导学补丁：主指令和模板明确主动评估外部视频，区分视频推荐与正文播放器；比赛 Demo 补充逐课视频任务及核验记录，不增加必看数量或新交互。
- 2026-10-06 路线布局修复：阶段标签不再固定宽高，长文字自然换行；首页模板明确数字、标题与状态的结构，兼容旧 span / eyebrow，避免标签溢出覆盖标题。
- 2026-10-06 首页主题修复：Hero 渐变、纹理、标题、标签与进度区跟随明暗模式，保留各视觉方向；长标题和进度说明可自然换行，打印隐藏装饰纹理。

## 1.0.0 · 首次公开发布 — 2026-09-28

- 面向任意知识与技能，以 Mission、学员画像、入门评估和动态 Roadmap 组织长期学习。
- 一次只生成一节 HTML 课程，依据学员答案、疑难与可验证表现选择推进、补救或深化。
- 区分知识、技能与现实判断，以及即时流畅表现和长期保持；支持主动回忆、复习与迁移。
- 提供紧凑响应式页面、导航、深浅色、折叠答案、代码复制、打印及图解/视频接入规范。
- 精选资源按具体目标导学，提供定位、任务、时间预算、访问限制与核验记录。
- 入门评估位于 `practice/entry-assessment.html`；作答支持浏览器副本、本地文件自动同步与备份导出。
- 提供 Windows、Linux、macOS 启动器；本地服务不可用时仍可静态阅读。
- 可选课内 AI 答疑按课保存聊天，统一在课程设置页配置服务、获取模型列表并选择模型；列表不可用时支持手动 ID。
- API Key 默认遮蔽、仅保留在服务会话内存；限定发送上下文，区分接口请求、认证和额度等错误。
- 提供课程隐私忽略模板、质量检查与可复用资产；不把 AI 示例、阅读或观看记录直接判为掌握。
