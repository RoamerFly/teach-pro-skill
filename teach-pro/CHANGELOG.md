# Teach Pro 版本记录

公开版本从 1.0.0 开始编号。此前开发阶段的迭代统一归入首发能力，不作为本仓库的公开版本历史。当前行为以 `SKILL.md` 和专项规范为准。

## 1.0.0 · 首次公开发布 — 2026-09-28

- 面向任意知识与技能，以 Mission、学员画像、入门评估和动态 Roadmap 组织长期学习。
- 一次只生成一节 HTML 课程，依据学员答案、疑难与可验证表现选择推进、补救或深化。
- 区分知识、技能与现实判断，以及即时流畅表现和长期保持；支持主动回忆、复习与迁移。
- 提供紧凑响应式页面、导航、深浅色、折叠答案、代码复制、打印及图解/视频接入规范。
- 精选资源按具体目标导学，提供定位、任务、时间预算、访问限制与核验记录。
- 入门评估位于 `practice/entry-assessment.html`；作答支持浏览器副本、本地文件自动同步与备份导出。
- 提供 Windows、Linux、macOS 启动器；本地服务不可用时仍可静态阅读。
- 可选课内 AI 答疑按课保存聊天，统一在课程设置页配置服务、获取模型列表并选择模型；列表不可用时支持手动 ID。
- API Key 默认遮蔽、仅保留在服务会话内存；限定发送上下文，区分接口请求、认证和额度等错误。
- 提供课程隐私忽略模板、质量检查与可复用资产；不把 AI 示例、阅读或观看记录直接判为掌握。
