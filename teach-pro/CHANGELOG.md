# Teach Pro 更新记录

## 1.2.0 — 2026-11-28

- 将学习目标、学员画像、入门评估、路线与逐课 HTML 教学连接为持续学习工作流。
- 按作答与疑难安排后续正式课，按需交付独立关联补充课，分别记录交付与掌握状态。
- 练习题后直接作答，本地自动保存；课内 AI 可参考当前最新输入与整门已生成教材。
- 支持多轮流式答疑、Markdown 排版、问题修改、回答重生成、分支切换、图片和文本附件、模型与思考程度选择。
- 统一模型及上下文设置，支持模型发现和通过系统凭据存储记住设备密钥。
- 本地服务支持 Python 3.10+，修复 Windows 含空格路径的课程环境切换。
- 整理当前示例与验证目录，归档历史路演制作材料，提供独立于比赛素材的 Skill 打包脚本。
- 新增跨平台自动检查、双版本安装包、校验值与标签驱动的 GitHub Release 发布。

## 1.0.0 — 2026-09-28

- 首次公开发布，以目标、学员画像、评估和动态路线组织长期学习。
- 提供网页课程、图解、练习、资源导学与本地学习记录。
