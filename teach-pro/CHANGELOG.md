# Teach Pro 版本记录

公开版本从 1.0.0 开始编号。此前开发阶段的迭代统一归入首发能力，不作为本仓库的公开版本历史。当前行为以 `SKILL.md` 和专项规范为准。

## 1.1.0-rc.7 · 学习记录稳定化 — 2026-10-03

- 恢复按字段合并，保留新输入、旧答案和明确清空的空值；同步限时并有限重连，修复首次读取失败后无法恢复的问题。
- 清空答案与疑难增加简短二次确认，取消不更改页面或文件；改选与确认清空同时重置测验反馈。
- 真实录制脚本适配流式端点并核对最终保存记录，综合验收移除旧预览/勾选断言；新增合成输入与录制核对回归。
- 共享组件与 Demo 同步，逐课教学主体不扩展；Word/视频仍待最终验收重制。

## 1.1.0-rc.6 · 紧凑流式答疑 — 2026-10-03

- 修复模型下拉框与获取按钮的外边距覆盖，统一控件高度；设置成功使用绿色，加载、修改和失败保持独立状态。
- 答疑输入框与发送按钮同行，移除常驻保存/快捷键说明，正常状态隐藏反馈行；保留输入法、引用、错误重试与本地保存。
- 新增真实 SSE 正文转发与增量 Markdown 排版，支持分块、多轮、部分回答恢复和浏览器离开后的保存；JSON 兼容接口在同一次请求内处理，旧非流式接口保留。
- 共享组件、专项规范、Demo 与合成回归同步；原始学员数据保持不变，Word/视频仍为 rc.4 快照。

## 1.1.0-rc.5 · 冻结课内工具栏 — 2026-10-03

- 内容区顶部冻结紧凑标题栏，唯一问 AI 按钮在最左侧，右侧展示“第 N 课 · 本课标题”与小字说明；使用主题渐变和强调分隔线区别于正文，阶段、时间和进度保留在栏下。
- 工具栏随导航折叠伸展，正文锚点避让，长文字和窄屏不撑宽；打印保留完整标题说明。旧课标题区由共享脚本适配，保留课文及记录。
- 模板、部署规范与 Demo 同步；教学主体未扩展，既有参赛文档/视频仍是 rc.4 快照，后续录制同步。

## 1.1.0-rc.4 · 课内答疑体验升级 — 2026-10-02

- 课页改为轻量入口与大弹窗多轮聊天，主题一致；支持引用、输入法保护、关闭中接收、历史滚动定位及复制/导出。
- 设置收敛为服务、遮蔽 Key、获取/选择模型与保存；高级参数折叠，移除重复勾选和上下文预览。
- 本地固定 Marked + DOMPurify 排版回答，保留许可证与原始 Markdown；不依赖 CDN 或新增学员安装步骤。
- 区分空/部分/异常回答及预算状态；DeepSeek 支持模型默认关闭思考，测试预算独立。重试关联原问题，近期上下文保持完整回合。
- schema 1 旧聊天可读、旧失败问题可重试；部署清单、只读检查器和 Demo 同步更新。教学决策主体未扩展，真实提供商复测与新版视频另行验收。

## 1.1.0-rc.3 · 稳定化候选补丁 — 2026-10-01

- 行内代码支持长地址换行，修复窄屏页面被 URL 撑宽的问题，代码块仍保留原有横向滚动。
- 在已有质量清单中明确本例约定与通用结论的区别，以及可运行示例、模拟和伪代码的标注；入口和主体功能保持冻结。
- 补充 TeleAgent G3 具体误区分支证据：答疑与定向选课成立，原生内容和状态一致性仍有失败项；人工修订不计为生成通过。

## 1.1.0-rc.2 · 稳定化候选补丁 — 2026-09-29

- 修复深色侧栏中课程品牌链接的低对比度，以及浅色课页横幅中信息标签的低对比度；候选课目文字统一使用侧栏配色。未扩展主体教学功能。

## 1.1.0-rc.1 · 稳定化候选 — 2026-09-29

- 选择题新增可复用片段与属性选择器样式回退；统一选项布局、选中态、聚焦态和检查按钮，兼容旧页面漏写样式类的情况。
- 主题切换改为导航底部圆角面板，向上展开、配色跟随主题；目录独立滚动，支持选中提示、键盘操作和偏好恢复。
- 画像模板加入信息来源与证据状态；评估区分原始事实、暂定解释及待验证能力，保留未知与学员自述。
- 新增只读课程结构检查，捕获异常 HTML 属性、题型数量不一致、链接与保存结构问题；概念与教学行为仍独立复核。
- 条件边界复核覆盖正文、图注、总结与测验反馈；宽 SVG 可在窄屏保持可读尺寸并在图框内滑动。
- 课程设置页与导航入口默认提供，AI 配置和答疑按需启用；未配置不阻碍学习，不自动请求模型。
- 页面模板内置设置入口与课页答疑脚本，恢复旧课程时补齐缺失组件并保留原始记录。
- 一手研究源头纳入按目标选材，学员页面只展示选定资源的导学，内部保留取舍记录。
- 入口指令去重，详细格式与安全边界仍在专项规范；建立比赛前的精简行为验收关卡。

## 1.0.0 · 首次公开发布 — 2026-09-28

- 面向任意知识与技能，以 Mission、学员画像、入门评估和动态 Roadmap 组织长期学习。
- 一次只生成一节 HTML 课程，依据学员答案、疑难与可验证表现选择推进、补救或深化。
- 区分知识、技能与现实判断，以及即时流畅表现和长期保持；支持主动回忆、复习与迁移。
- 提供紧凑响应式页面、导航、深浅色、折叠答案、代码复制、打印及图解/视频接入规范。
- 精选资源按具体目标导学，提供定位、任务、时间预算、访问限制与核验记录。
- 入门评估位于 `practice/entry-assessment.html`；作答支持浏览器副本、本地文件自动同步与备份导出。
- 提供 Windows、Linux、macOS 启动器；本地服务不可用时仍可静态阅读。
- 可选课内 AI 答疑按课保存聊天，统一在课程设置页配置服务、获取模型列表并选择模型；列表不可用时支持手动 ID。
- API Key 默认遮蔽、仅保留在服务会话内存；限定发送上下文，区分接口请求、认证和额度等错误。
- 提供课程隐私忽略模板、质量检查与可复用资产；不把 AI 示例、阅读或观看记录直接判为掌握。
