# LEARNER-PROFILE.md Format

```md
# Learner Profile

## Background
- 已有知识：
- 相关经验：
- 已完成项目/课程：

## Current ability
- 能独立完成：
- 需要提示才能完成：
- 尚未理解或从未接触：

## Learning preferences
- 偏好表示：图解 / 实例 / 推导 / 练习 / 项目 / 对话 / 其他
- 解释深度：
- 代码、公式或术语接受程度：
- 喜欢的反馈方式：

## Schedule
- 每天或每周可投入：
- 常用学习时段：
- 截止日期：

## Environment
- 设备与软件：
- 可访问网站或平台：
- 语言：
- 预算或材料限制：

## Known misconceptions or blockers
- {具体误区或障碍}

## Confidence notes
- 用户自评：
- 通过表现确认：
- 尚需验证：
```

## 规则

- 区分用户自述与已验证能力。
- 只记录会改变教学决策的信息。
- 持久偏好可以同步写入 `NOTES.md`。
- 不把一次偶然表现固化为长期标签。
