# LEARNER-PROFILE.md Format

```md
# Learner Profile

## Evidence basis
| 教学相关信息或判断 | 来源与位置 | 证据状态 | 可采用范围 / 待验证 |
| --- | --- | --- | --- |
| {具体信息} | {本轮提示或本课程文件、字段、日期} | {待确认 / 自述 / 单题线索 / 经表现验证} | {证据实际支持什么；未知可保留} |

## Background
- 已有知识：
- 相关经验：
- 已完成项目/课程：

## Current ability
- 能独立完成：
- 需要提示才能完成：
- 待验证或已展示的具体缺口：{未知时写待验证，不推断从未接触}

## Learning preferences
- 偏好表示：图解 / 实例 / 推导 / 练习 / 项目 / 对话 / 其他
- 解释深度：
- 代码、公式或术语接受程度：
- 喜欢的反馈方式：

## Schedule
- 每天或每周可投入：
- 常用学习时段：
- 截止日期：

## Environment
- 设备与软件：
- 可访问网站或平台：
- 语言：
- 预算或材料限制：

## Known misconceptions or blockers
- {具体误区或障碍}

## Confidence notes
- 用户自评：
- 通过表现确认：
- 尚需验证：
```

## 规则

- 先填写证据依据，再概括各栏目；栏目可写“待确认/暂无证据”，不为填满模板补造背景。具体时间、设备、经历或偏好来自历史上下文时注明来源，并在本轮确认前保留待确认状态。
- 自述、单题线索与经表现验证不能互换；教学起点是暂定安排，不等于已证实缺口。首页、Mission、Roadmap 与 Confidence 沿用同一证据范围，不只在本文件加免责声明。
- 只记录会改变教学决策的信息。
- 持久偏好可以同步写入 `NOTES.md`。
- 不把一次偶然表现固化为长期标签。
