# 校园消费统计 · 最小输入输出示例

用于理解 Teach Pro 的典型调用与交付边界。学生、答案及页面均为合成夹具，不是学员成绩或 TeleAgent 新生成结果。教学规则仍以 [SKILL.md](../../../SKILL.md) 为准。

需要查看更完整的讲解、两种作答的续课结果及文件证据对应时，使用[完整自适应案例](../statistics-adaptive/README.md)；本最小示例继续用于快速组件复现。

## 从一句话开始

输入：`@teach-pro 我想学习统计学。`

预期先问目标和基础，如“你更想用于考试、读论文，还是分析实际数据？学过哪些统计内容？”依据回答再了解时间和偏好。不要预设学生会 Python、有三个月期限或要考某个证书；已知信息不重复问。此阶段不批量写课程。

## 明确目标后先评估

输入：`@teach-pro 我是大学生，想读懂校园消费调查里的数字。能做基本四则运算，还分不清均值与中位数；每周两小时，喜欢先看图再算。先评估我的基础再开课。`

预期交付课程首页、入门评估、设置页、画像与候选路线。第一课尚未生成，能力待验证，设置不必配置。构建器的 assessment 阶段演示这个输出形态。

评估共一题选择、一题解释：计算五天消费的均值；说明自己的计算过程。答案可保存，但勾对选择项不能直接升级为稳定掌握。

## 作答后开第一课

模拟提交：`entry-mean="mean-30"`，`entry-explanation="10+20+20+30+70=150，150÷5=30；我还不清楚中位数怎么算。"`

输入：`我已提交入门评估，请读取本地答案，生成第一课。`

预期读取当前课程文件，交付一节“均值与中位数”的正式 HTML；根据计算解释暂定起点，不宣称长期掌握。新课完整解释两种统计量、极端值影响与适用条件，课末收新作答和疑难。构建器的 lesson 阶段提供该页面形态；不会预填模拟提交或生成学习能力结论。

## 学完之后如何决定

| 下一轮输入 | 预期决策 |
| --- | --- |
| “为什么加上一个 1000 后中位数也变了？” | 围绕当前课解释：新增观测改变样本数与中间位置，不自动开第二课。 |
| 解释“同样五人中，只把最大值从 70 换成 700，中位数仍为 20，均值变成 156”，并要求下一课 | 可以推进分布与离散程度的新目标；这只支持本题理解，不宣称所有极端值情形已掌握。 |
| 认为“只要有很大的数字，中位数就一定等于均值”，并要求下一课 | 一节新的正式课配套第 1 课补充页，换例纠正与复核；不以旧题训练取代正式课。 |
| 只说“看完了，懂了，继续” | 保持能力待验证，安排短检查或补充，同时提供完整新正式课，不记为已掌握。 |

正式课示例命名 `lessons/0002-spread.html`，关联补充页 `lessons/0001-s01-outlier-check.html`；没有实际生成就不添加可点击链接。参照 [正式与补充课规则](../../../LESSON-DELIVERY-POLICY.md)。

## 离线复现与检查

在 Skill 根目录运行，需要 Python 3.11+，输出目录必须尚不存在：

```sh
python scripts/build_example.py <新的输出目录> --stage assessment
python scripts/check_course.py <输出目录> --json
```

换一个新输出目录，加 `--stage lesson` 可构建四页的首课结果；默认 assessment 只有三页，不生成正式课。打开 `index.html` 即可阅读；需要文件同步时使用输出目录中的启动器。无需配置模型，不自动联网。

页面内容来自 [评估题面](./assessment-questions.html)与[首课正文](./lesson-body.html)，组装现有共享模板、样式、交互和服务；没有第二套 Runtime。片段本身不作为独立课程页打开。构建器不运行教学 AI，静态检查通过不能证明上述教学决策已由某个宿主执行。

验收时实际选择错误项、检查反馈、改选正确项，再填写解释并刷新确认恢复；从启动器打开后核对 learner-submissions 文件。源包不包含学员原始记录、聊天或密钥。
