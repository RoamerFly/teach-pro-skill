# RESOURCES.md Format

`RESOURCES.md` 是内部已核验资源库，不是直接倾倒给用户的书签列表。每节课只从中选取与当天目标高度相关的少量资源。

```md
# {主题} Resources

## Knowledge

### {资源精确标题}
- 类型：官方文档 / 文章 / 论文 / 书籍章节 / 视频 / 练习
- 来源：{机构或作者}
- URL：{精确链接}
- 语言：中文 / 英文 / 其他
- 适用版本：{如适用}
- 精确位置：{章节锚点、P 数、时间段、页码}
- 对应知识点：{具体到某个课程目标}
- 推荐原因：{为什么可信且适合当前用户}
- 导学角色与优先级：{主读/视频精学/安全或实践映射/进阶；优先/选读/后续候选}
- 对应阶段/课程：{已生成课或候选阶段，不虚构未来课正文}
- 学习任务与产出：{看前预测、阅读/暂停任务、看后闭卷解释或迁移}
- 预计时间：{分钟}
- 访问限制与替代：{语言、字幕、登录/付费/网络限制；无需该资源的路径}
- 最后核验：{YYYY-MM-DD}
- 核验程度与缺口：{正文/目录/公开简介/实际播放；未确认哪些部分}

## Practice
{具体题组、工具或练习页面，字段同上。}

## Wisdom / Communities
{高质量社区、线下课程或专业反馈渠道；只有用户愿意时使用。}

## Gaps
- {当前缺少可靠资源的具体部分}
```

## 规则

- 裸链接无效，必须注释用途和精确位置。
- Knowledge 资源优先官方、原始、同行评审或公认专家来源；不要把模型记忆作为易变化事实的唯一依据。
- 优先官方、原始和高可信来源。
- 视频尽量精确到单集、分 P 和时间段。
- 资源过时、失效、过浅或偏离使命时应删除或标注；宁可保留少量高信号资源，也不要积累资源坟场。
- 课程 HTML 通常呈现 1–3 项互补资源，确有互补价值时可增加；优先项 1–2 项，其余选读，不把数量当指标。资源中心可按阶段组织更广的候选清单，不要求全部完成。
- 公开简介核验、播放器验证与完整内容核验分别记录；历史核验日期不可统一改成今天。
- Wisdom / Communities 仅在确实需要真实世界反馈且用户愿意时推荐；若用户明确不希望加入社区，应记录该偏好，后续不反复建议。
