# Teaching Modes

根据学习目标选择一种主模式和必要的辅模式，不要按学科名称机械判断。

## 概念理解型

适合理论、科学、哲学、机制、制度等。

推荐结构：现象或问题 → 直觉 → 定义 → 机制 → 反例 → 预测 → 迁移。

理解证据：能解释因果链、辨析相近概念、预测条件变化后的结果。

## 记忆型

适合词汇、术语、事实框架、分类、规则表。

推荐结构：意义化组块 → 线索 → 主动回忆 → 间隔复习 → 延迟提取 → 混合检索。

重点区分刚学习后的流畅度与隔一段时间后的存储强度；不要用连续重复阅读制造“已经记住”的错觉。

避免：只让用户反复阅读或抄写。

## 问题求解型

适合数学、物理、算法、逻辑、计算和题型训练。

推荐结构：识别问题结构 → 选择策略 → 完整示例 → 半完成例题 → 独立题 → 变式 → 错因归类。

避免：只展示答案或连续堆例题。先建立可用的策略心智模型，再通过变式和交错练习增加有益难度。

## 操作技能型

适合软件操作、实验、维修、烹饪、手工和工作流程。

推荐结构：目标结果 → 工具与前提 → 分步操作 → 检查点 → 常见失败 → 真实执行 → 反馈。

理解证据：能完成操作并根据检查点纠错。

## 语言沟通型

适合外语、表达、演讲、写作和沟通。

推荐结构：可理解输入 → 结构拆解 → 模仿 → 受控输出 → 情境输出 → 纠错 → 再表达。

## 创作型

适合设计、绘画、音乐、故事、摄影等。

推荐结构：目标审美 → 作品拆解 → 原则 → 限制性练习 → 小作品 → 反馈 → 二次修改。

避免：只有抽象审美评价，没有可执行修改。

## 决策判断型

适合法律、管理、投资判断、诊断、评估和策略。

推荐结构：目标 → 证据 → 假设 → 选项 → 权衡 → 情景 → 反事实 → 决策规则。

理解证据：能指出结论对哪些假设敏感。

## 考试型

适合资格考试、升学考试和认证。

推荐结构：考纲映射 → 能力诊断 → 高频题型 → 得分策略 → 定时练习 → 错题模式 → 回炉计划。

避免：为了刷题跳过导致重复错误的底层知识。

## 项目型

适合以作品、产品、论文或真实任务为目标。

推荐结构：可交付物 → 里程碑 → 必要知识 → 最小实践 → 评审 → 迭代 → 复盘。

## 身体技能型

适合运动、舞蹈、发声和身体动作。

推荐结构：前提与风险 → 动作目标 → 关键姿势 → 慢速分解 → 感觉线索 → 录像或教练反馈 → 渐进练习。

不要仅靠文字声称已纠正现实动作；明确需要外部观察或专业反馈的环节。
