# Learning Record Format

学习记录位于 `learning-records/`，按 `0001-slug.md` 顺序编号。它记录会改变后续教学决策的真实学习证据，而不是会话日志。

## 最小模板

```md
# {学会或确认的内容}

{1–3 句：用户展示了什么能力，证据是什么，为什么会改变下一步教学。}
```

## 可选字段

```md
Status: active | superseded by LR-NNNN

## Evidence
- 层级：识别 / 解释 / 区分 / 预测 / 应用 / 迁移
- 表现：{具体证据}

## Remaining gaps
- {尚未解决的误区、边界、前置或应用困难}

## Implications
- {下一课可以跳过什么、应补什么、能解锁什么}
```

## 何时写

- 用户展示了非平凡理解。
- 用户提供了可信的既有能力证据。
- 一个重要误区已被纠正并通过新题验证。
- 学习使命因学习结果发生变化。

## 不能作为证据

- 课程被生成、阅读或观看。
- 用户回复“知道了”“继续”。
- 用户只看到了正确答案。
- AI 认为解释得足够好。
- 浏览器显示“已保存”，但 AI 尚未收到实际答案。

网页输入记录与本目录不同：前者是学员原始答案、疑难和作品说明，可自动同步到课程工作区的 `learner-submissions/`；未同步时只保存在浏览器，可由学员导出。本目录是 AI 读取并审阅这些材料后写下的证据判断。下一课生成前，先回应未解决问题，再根据独立完成程度和迁移表现决定推进、补救或深化；不要仅凭“已填写”判定掌握。

后续发现理解有误时，不删除历史记录；标为被新记录取代。
