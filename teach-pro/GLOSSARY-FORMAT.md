# GLOSSARY.md Format

`GLOSSARY.md` 是当前课程的统一语言，也是“已被压缩的理解”记录。它不是让用户第一次学习概念的百科词典；只有学习者已经理解并能正确使用的术语才进入这里。

```md
# {主题} Glossary

{1–2 句说明术语表覆盖的范围。}

## {可选分类}

**术语**：
{1–2 句准确定义。优先说明“它是什么”，必要时补充关键条件。}
_别名或避免用语：{如适用}_
_边界：{容易混淆、领域内含义不一致时说明}_
```

## 规则

- **理解后再加入。** 新接触、刚读过或能复述原句不等于掌握；至少要有解释、区分、应用或其他合适证据。
- **定义要短而可复用。** 一到两句为主，便于后续课程直接调用。
- **统一术语。** 同一概念有多个说法时，选一个主术语，其他列为别名或避免用语，减少语言噪声。
- **允许用已掌握术语定义新术语。** 这样术语体系会逐步形成压缩的知识网络。
- **显式处理歧义。** 若行业、教材或社区对某词用法不同，说明本课程采用的含义和边界。
- **理解深化后原地修订。** 不保留已经确认错误或过时的定义；需要历史轨迹时由 learning record 记录变化。
- **按自然主题分组。** 术语较少可保持平铺，出现稳定簇后再增加小节。
- HTML 参考页可以从术语表生成，但 Markdown 仍是 AI 的规范源。
