# 学途智伴 1.2.0

学途智伴将学习目标、网页课程与本地学习记录连接起来，支持从基础评估到持续续课的完整学习流程。

- 主动了解目标与基础，逐课生成图解、示范、练习和资源导学。
- 正式课推进新目标，关联补充课处理具体疑难；续课读取作答、疑难与聊天记录。
- 课内 AI 支持流式多轮答疑、当前页与整门教材上下文、即时作答、分支修改和附件。
- 本地服务支持 Python 3.10+；设备密钥通过系统凭据存储恢复，修复 Windows 含空格路径的启动问题。
- 整理示例与验证目录，将历史路演制作材料移出活跃仓库；保留最新演示、课程与可复现测试。
- 新增 Windows、macOS、Linux 与 Python 3.10 / 3.12 的自动化检查，以及标签驱动的 Release 构建与发布。

## 下载与安装

- `teach-pro-1.2.0.zip`：日常使用版，解压后将 `teach-pro/` 导入 TeleAgent 等支持 Skill 的 Agent。
- `teach-pro-1.2.0-competition.zip`：赛事版，提供中文顶层元数据与整理后的参考目录。
- `SHA256SUMS`：下载文件校验值。
- `release-manifest.json`：来源提交、包大小、文件数与运行代码一致性记录。

两种 Skill 包使用同一套教学与运行代码。也可在支持 Skills CLI 的环境中运行：

```sh
npx skills add RoamerFly/teach-pro-skill@v1.2.0 --skill teach-pro
```

生成课程后，从课程目录运行对应平台的 `start-course` 启动器。已有课程可更新共享运行组件，继续使用原来的作答、聊天与模型设置。

本项目以 [mattpocock/skills 的 teach Skill](https://github.com/mattpocock/skills/blob/main/skills/productivity/teach/SKILL.md) 为基座，上游 MIT 版权与许可随技能包保留。
